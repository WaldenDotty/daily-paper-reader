## 摘要
随着未来几年月球探索的加速，对航天器定位、导航与授时的标准化需求已经迫在眉睫，因此也迫切需要定义月球参考系统与参考框架。本文档汇集了国际大地测量学协会（IAG）/国际天文学联合会（IAU）联合工作组（WG）1.1.3“月球参考框架”关于该主题的最新建议。尽管由于控制点数量有限且数据类型单一，建立月球参考系统与框架面临挑战，工作组仍提议采用为全球导航卫星系统（GNSS）开发的方法。这有助于建立一个精确可靠的参考系统，与国际地球自转与参考系统服务（IERS）标准保持一致，并基于冗余数据源确保月球定位、导航与授时（PNT）框架的韧性。国际月球参考框架2026（ILuRF2026）的首个实现已在临时网站https://ilurs-6e772d.gitlab.io/及未来网站http://ilurf.gssc.esa.int上发布，并附带相关软件。

## Abstract
As the exploration of the Moon accelerates in the coming years, there is already an urgent need to standardise the Position, Navigation and Timing of spacecraft, and consequently for the definition of the lunar reference system and frame. This document gathers the most recent recommendations of the the International Association of Geodesy (IAG) / International Astronomical Union (IAU) Joint Working Group (WG) 1.1.3 "Lunar Reference frames" on the topic. Despite the challenges for producing a Lunar Reference System and Frame due to the limited number of control points and a single data type, the WG proposes applying an approach developed for Global Navigation Satellite Systems (GNSS). This supports an accurate and reliable reference system, consistent with International Earth Rotation and Reference Systems Service (IERS) standards and, based on redundant sources, ensures resilience for the lunar Position, Navigation and Timing (PNT) framework. The first realization of the International Lunar Reference Frame 2026 (ILuRF2026), ILuRF2026, is delivered on the temporay website https://ilurs-6e772d.gitlab.io/ and on the future http://ilurf.gssc.esa.int together with associated software.

### 2. 方法论：核心思想、关键技术细节

#### 2.1 ILuRS的总体框架定义

- **参考系结构选择**：定义ILuRS时，考虑了两种框架结构：
  - **ME框架（Mean-Earth frame）**：基于平均地球-月球定向（x轴指向从月球看到的平均地球方向，z轴沿平均自转极）。
  - **PA框架（Principal Axis frame）**：基于月球惯量矩阵对角化。
- **ILuRS的最终选择**：采用PA框架作为自然选择，原因有二：
  - 它直接由月球历表中的欧拉角定义；
  - ME框架需要额外的平均处理，可能引入误读和偏差。
  - 同时也提供与ME等替代框架之间的Helmert变换参数，确保可访问性和未来灵活性。
- **参考月球概念**：ILuRS与月球共旋转，锚定在一个"未变形参考月球"——一个几何理想、未变形的天体，定义在主轴（PA）框架中，潮汐、自转和弹性变形后续作为修正项附加。

#### 2.2 ILuRF2026的实现方法：借鉴GNSS的多源加权组合

- **输入数据**：选用2025年最先进的三种月球/行星历表：
  - DE430（JPL）
  - INPOP21a（IMCCE）
  - EPM2021（IAA RAS）
- **核心组合算法**：采用类似GNSS轨道组合的加权平均方法——借鉴Beutler等人（1995）为IGS分析中心开发的轨道组合方法。具体步骤如下：
  1. 使用简化方差分量估计器（VCE）确定三种历表的权重；
  2. 对月球位置、速度、定向角（PA框架中）进行一致性加权；
  3. 最终归一化权重分别为：
     - EPM2021：0.451454072137127
     - INPOP21a：0.380949596178373
     - DE430：0.167596331684500
  4. 同一权重也应用于原点与定向参数的组合。
- **该方法的优势**：
  - 避免依赖单一历表提供者；
  - 产生单一标准化的ILuRF；
  - 未来可随改进历表更新；
  - 有助于识别异常值（如DE440的问题）。

#### 2.3 ILuRF2026的组成内容

ILuRF2026交付物（提供TCB和TCL两个版本）包括：
- **原点定义**：月球质心相对地球的位置和速度（BCRS框架，TDB时标）；
- **定向定义**：月球天平动的欧拉角（TDB和TCL时标）；
- **具体化（materialization）**：月球激光测距后向反射器（LLRRR）坐标（TDB和TCL）；
- **时间尺度**：月球质心处的TCL-TCB时间序列。

#### 2.4 时间尺度计算（TCL）

- 使用自主开发的**TEMPUS**开源Python库——依据IAU 2000和2024决议计算太阳系行星和卫星的坐标时。
- 通过对比已发表的TCL-TCB（如Klioner 2025和Lu等2025）进行基准验证，差异低于5×10⁻¹⁷漂移和65ps去趋势残差，远小于当前原子钟的稳定性和精度。
- 由于ILuRS是月心系统，TCL不是直接计算，而是利用同一组权重对三种历表计算出的TCL进行加权平均。

### 6. 主要结论与发现

1. **ILuRS采用PA框架**作为自然参考系，以月球质心为原点，由历表欧拉角直接确定方向，更稳健且更易访问。
2. **借鉴GNSS组合方法可行且有效**：采用VCE加权平均的三种SOA历表组合结果与权重最高的EPM2021表现一致，LLR残差表现良好（RMS 1.7-3.3cm），证明了多源冗余组合策略的成功。
3. **ILuRF2026已正式发布**：首个实现版本在临时网站和ESA GSSC网站上提供，附带LOOP时间序列、LLRRR坐标、Helmert变换参数、TCL时间尺度和基于Python的插值软件。
4. **ILuRS的时间尺度TCL计算可行**：TEMPUS软件验证表明不同历表导致的TCL-TCB差异（漂移<2×10⁻¹⁸，最大振幅<65ps）远低于当前时钟精度，不影响实际应用。
5. **未来改进方向明确**：月球南半球的VLBI站（如ESA的NovaMoon/Argonaut任务，2029年）是最高效的改进手段，有望将LOOP定义改善75%；ILuRS已被提议纳入国际地球自转与参考系统产品中心（2026年5月接受）。

### 7. 优点（方法或实验设计上的亮点）

- **多源冗余策略**：借鉴GNSS领域的成熟组合方法（VCE），不依赖单一历表提供者，增强了参考系统的韧性与可靠性，符合"冗余增强弹性"的工程理念。
- **标准化与兼容性**：遵循IERS标准，同时提供到其他参考框架（PA和ME）的变换参数，具有良好的互操作性；支持TCB与TCL双时标版本，适配不同用户需求。
- **完整的交付物设计**：不仅提供参考框架本身，还附带插值软件、辅助参数（如EMRAT、GM、h2等）、验证工具，降低了使用门槛。
- **严谨的验证流程**：采用多软件独立验证、多站点对比，基准测试与已发表时间序列一致性非常好（优于5×10⁻¹⁷漂移），科学可信度高。
- **开放可访问**：提供了临时网站和未来永久网站，开源TEMPUS软件，促进透明研究和广泛使用。
