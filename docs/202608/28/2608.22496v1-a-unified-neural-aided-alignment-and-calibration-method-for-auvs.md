## 摘要
自主水下航行器（AUV）依靠惯性导航系统（INS）和多普勒测速仪（DVL）的融合实现精确导航。在部署前，该融合需要一个DVL初始化流程，包括两个阶段：对准（估计INS与DVL坐标系之间的旋转）和校准（估计DVL误差项）。传统上，这两个阶段均通过基于模型的算法求解，这些算法要求复杂的载体机动、水面卫星参考测量和简化的误差模型，导致初始化耗时、依赖轨迹且对传感器质量敏感。本文提出一种全神经辅助的DVL初始化流程，使用两个互补的神经网络替代上述两个阶段：ResAlignNet用于对准，DCNet用于校准。该统一流程在单一近似匀速轨迹上原位运行，且使用与基于模型基线相同的输入。利用五种不同传感器误差组合下记录的真实数据，该流程仅使用25秒的初始化数据，相比基于模型的基线，将速度均方根误差平均降低了68.7%。

## Abstract
Autonomous underwater vehicles (AUVs) rely on the fusion of inertial navigation systems (INS) and Doppler velocity logs (DVL) for accurate navigation. Before deployment, this fusion requires a DVL initialization pipeline consisting of two stages: alignment, which estimates the rotation between the INS and DVL frames, and calibration, which estimates the DVL error terms. Conventionally, both stages are solved with model-based algorithms that demand complex vehicle maneuvers, surface-level satellite reference measurements, and simplified error models, making initialization time-consuming, trajectory-dependent, and sensitive to sensor quality. In this work, we propose a fully neural- aided DVL initialization pipeline that replaces both stages with two complementary neural networks: ResAlignNet for alignment and DCNet for calibration. The unified pipeline operates in situ on a single nearly constant-velocity trajectory and uses the same inputs as the model-based baseline. Using real-world data recorded across five distinct sensor error-term combinations, the proposed pipeline reduces the velocity root mean squared error by an average of 68.7% over the model-based baseline, using only 25s of data for initialization.

## 1. 核心问题与整体含义

- **领域背景**：AUV在水下无法依赖GNSS，导航精度取决于INS/DVL融合；INS提供高频但漂移的姿态/速度，DVL提供相对海底的无漂移速度。
- **关键瓶颈——DVL初始化**：部署前必须执行初始化流程，包含两个顺序阶段：
  - **对准（Alignment）**：估计INS体坐标系与DVL坐标系之间的旋转矩阵 $T_{db}$；即使小的对准误差也会在运行中积累为大的导航位置误差。
  - **校准（Calibration）**：估计DVL确定性误差项，即每轴尺度因子 $k_{DVL}$ 和偏置 $b_{DVL}$。
- **传统方法的痛点**：基于模型的算法（SVD求解Wahba问题 + GNSS辅助标量尺度因子校准）需要复杂的激励机动、水面GNSS参考、简化的标量误差模型，导致：
  - 初始化耗时长；
  - 结果依赖轨迹；
  - 对传感器质量敏感；
  - 需要外部基础设施（如声学信标）。
- **本文的核心贡献**：提出一个完全数据驱动的统一管道，用两个神经网络分别替代初始化的两个阶段，在保持相同输入的前提下实现：
  - 无需外部基础设施；
  - 仅在单一近似恒速轨迹上即可完成初始化；
  - 只用25秒数据即可获得比传统方法更高的精度（平均VRMSE降低68.7%）。

## 2. 方法论

### 2.1 总体框架

- 统一的端到端DVL初始化管道，链式连接两个神经网络：
  - **ResAlignNet**：将对准问题转化为监督回归任务，直接估计INS体坐标系与DVL坐标系之间的旋转（三个Euler角 $\phi, \theta, \psi$）。
  - **DCNet**：在对准之后，估计DVL每轴的尺度因子向量 $k_{DVL} \in \mathbb{R}^3$ 与偏置向量 $b_{DVL} \in \mathbb{R}^3$。
- 两个网络的输入与基于模型的传统基线完全一致（同步的INS和DVL速度窗口），不引入额外传感器或测量。

### 2.2 ResAlignNet（对准阶段）

- **网络架构**：一维ResNet-18变体。
  - 输入：同步INS和DVL速度窗口拼接，形状为 `[window size × 6]`，六通道为两个传感器的三轴速度分量。
  - 初始宽卷积后跟随四个残差层，通道数逐层扩展（64→128→256→512），跳跃连接保证噪声下的梯度流与特征提取。
  - 全局平均池化压缩时间维度，全连接层输出三个Euler角。
- **训练目标**：预测Euler角与真值之间的MSE，即 $MSE = \frac{1}{N} \sum_{i=1}^{N} \sum_{j \in \{\phi,\theta,\psi\}} (\alpha_{i,j} - \hat{\alpha}_{i,j})^2$。
- **优势**：无需规定的机动模式或外部定位，直接在速度窗口上运行。

### 2.3 DCNet（校准阶段）

- **网络架构**：多输入头卷积网络。
  - 输入：对齐后体坐标系中的DVL速度与参考速度（GNSS），形状为 `[6 × window size]`。
  - 一维卷积头处理两个速度向量的逐元素差值——在误差模型下该差值隔离了尺度因子的贡献。
  - 二维卷积头采用扩张卷积核，联合处理两个向量对应的轴。
  - 两个头的输出拼接后经过全连接层，输出六个误差项（每轴一个尺度因子和一个偏置）。
- **误差模型**：采用六项向量误差模型 $\tilde{v}_d = (1 + k_{DVL}) \hat{T}_{db} v_{GNSS}^b + b_{DVL} + \delta v_d$，与传统的统一标量尺度因子模型相比，允许每轴独立的尺度因子与偏置，实现更精确的逐轴校正。
- **训练目标**：直接最小化校准后速度与参考速度之间的MSE（不是误差项本身的MSE），即 $MSE = \frac{1}{N} \sum_{i=1}^{N} \sum_{j \in \{x,y,z\}} (y_{i,j} - \hat{y}_{i,j})^2$，其中 $y$ 为参考速度，$\hat{y}$ 为校准后速度。

### 2.4 端到端推理流程

- 给定校准轨迹：
  1. ResAlignNet估计对准旋转 $\hat{T}_{db}$；
  2. 用 $\hat{T}_{db}$ 将DVL速度变换到体坐标系；
  3. 将对齐后的DVL速度与参考速度输入DCNet，估计每轴尺度因子和偏置；
  4. 上述对准与误差项构成完整的DVL初始化结果，可应用于任意评估轨迹的校正。
- 整个流程只消费速度窗口，因此可在单一近似恒速轨迹上原位运行，彻底消除了传统管道对机动和表面参考的要求。

## 6. 主要结论与发现

- **核心结论**：统一神经辅助管道可以替代传统SVD+标量尺度因子的DVL初始化，且使用相同输入、在恒定速度轨迹上运行。
- **精度提升**：
  - 平均VRMSE从基线的0.5768 m/s降至0.1803 m/s，降低68.7%；
  - 5组组合中提升幅度为16.4%–83.5%，其中ETC3（最激进组合、基线最差）提升最高达83.5%；
  - 所有组合下本文方法的VRMSE均低于0.21 m/s，而基线在ETC3下接近1.0 m/s。
- **对准是主导误差源**：仅ResAlignNet（不校准）的平均VRMSE即为0.1843 m/s，远低于基线，说明对准误差的修正贡献最大。
- **校准是次要精炼**：加入DCNet将平均VRMSE从0.1843降至0.1803（再降2.2%），其中4/5组合有改善（最高7.4%），但ETC3反而有轻微退化（0.1528→0.1623）。
- **操作便捷性三方面**：
  1. 无需外部定位设施；
  2. 无需专用机动，恒速轨迹即可；
  3. 25秒内即可获得稳定精度，大幅缩短任务准备时间。

## 9. 综合评述与学术定位

- **总体定位**：本文是一篇探索数据驱动方法替代传统模型驱动DVL初始化的技术报告。其核心贡献不在于提出全新的网络结构（ResNet-18变体与多头CNN均为成熟架构），而在于将神经网络成功嵌入到原本依赖手工建模与特定机动的工程流程中，并验证了“以数据驱动简化操作”这一思路的可行性。
- **方法论的意义**：将初始化问题拆解为两个子问题并分别用网络解决，保持了与经典流程的对齐性，便于工程理解和模块替换。这一“神经替代”范式可能对水下导航的其他校准环节（如罗盘校准、声学基阵校准）有借鉴意义。
- **实验设计的典型性**：使用真实海试数据、五种误差组合、消融分析、固定初始化时长等设计符合机器学习系统评估的基本规范，但规模偏小、泛化性证据不足，属于“概念验证”级别，尚不足以直接支持大规模部署。
- **对领域的影响判断**：若后续工作能在更多载体、更复杂真实误差（而非叠加噪声）下复现类似增益，该方法有望成为DVL初始化操作的重要替代方案；当前版本则更适合作为后续研究的基础框架。

## 10. 可能的改进方向（作者未深入讨论的潜在延伸）

- 将两个独立网络改为端到端联合训练，允许对准误差在反向传播中指导校准网络学习更合理的特征耦合，可能解决ETC3下校准退化的现象。
- 引入不确定性估计（如MC-Dropout或概率输出），让系统在低置信度时提示操作员延长观测时间，提升实际部署的可靠性。
- 在完整导航解（位置/航向）层面做端到端评估，以直接量化初始化质量对任务性能的影响。
- 探索真值标签获取困难场景下的自监督/半监督训练策略（如利用闭环约束生成伪标签），降低对高精度标注数据的依赖。
- 将网络输出嵌入扩展卡尔曼滤波（EKF）中，作为时变参数在线微调，替代当前一次性离线初始化的范式。

## 11. 总结（一句话概括）

本文提出了一种由ResAlignNet和DCNet组成的神经辅助DVL初始化管道，在相同输入与单条恒速轨迹条件下，用25秒数据将速度估计的VRMSE从基线的0.5768 m/s降至0.1803 m/s（降低68.7%），显著简化了操作流程并提升了精度；但其实验规模有限、校准模块增益微小且缺乏任务级验证，目前更适合作为概念验证而非可直接部署的成熟解决方案。
