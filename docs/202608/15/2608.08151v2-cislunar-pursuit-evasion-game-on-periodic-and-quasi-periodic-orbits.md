## 摘要
地月空间航天器运行在非线性且不稳定的环境中，这使得防御性机动规划变得困难。我们将地月空间航天器的追逐与规避问题建模为圆型限制性三体问题中的零和微分博弈。每艘航天器控制其推力和参考轨道相位，从而能够在沿周期轨道运动及穿越拟周期环面的同时保持在参考轨道附近。我们采用一种强制执行硬输入约束的约束离散时间微分动态规划方法来求解该博弈。我们提出了一种共享时间正则化方法，以在细化临近月球近距离飞越附近的离散化时同步两艘航天器的运动。在周期和拟周期轨道上的数值结果表明，相位控制提高了机动灵活性，同时限制了对参考轨道的偏离。离散时间方法相较于连续时间公式还具有巨大的计算优势。准晕轨道与准近直线晕轨道的比较表明，近月飞越创造了更大的逃逸机会，但也增加了交会的敏感性。这些结果表明，参考轨道几何结构是地月空间防御性任务设计中的一个重要组成部分。

## Abstract
Cislunar spacecraft operate in nonlinear and unstable environments that make defensive maneuver planning difficult. We formulate cislunar spacecraft pursuit and evasion as a zero-sum differential game in the circular restricted three-body problem. Each spacecraft controls its thrust and reference orbit phase, enabling motion along periodic orbits and across quasi-periodic tori while remaining near the reference. We solve the game using a constrained discrete-time differential dynamic programming method that enforces hard input constraints. We propose a shared time regularization to synchronize both spacecraft while refining the discretization near close lunar passages. Numerical results on periodic and quasi-periodic orbits show that phase control improves maneuvering flexibility while limiting departure from the reference orbit. The discrete-time method also provides a large computational advantage over a continuous-time formulation. Comparisons between quasi-halo and quasi-near-rectilinear halo orbits show that close lunar passages create larger escape opportunities but also increase the sensitivity of the encounter. These results show that reference orbit geometry is an important part of defensive cislunar mission design.

## 2. 提出的方法论

### 2.1 核心思想

- 将追逃问题建模为**零和微分博弈**，状态由双方航天器的物理状态（位置、速度）和参考相位组成。
- 每方航天器的控制量包括**推力矢量**（3维）和**参考相位速率**（周期轨道为1维，拟周期轨道为2维），从而允许航天器在参考流形上“沿轨调速”或“横向转移”。
- 使用**离散时间微分动态规划**（DT-DDP）求解博弈，而非连续时间公式，以避免连续时间下昂贵的 Riccati 方程积分，并适应约束处理。
- 引入**共享多智能体时间正则化**（Multi-Agent Time Regularization），基于 Sundman 变换和 Kustaanheimo-Stiefel（KS）正则化，在公共物理时间下同步双方，并在任一方接近月球时自动增加时间分辨率。

### 2.2 关键技术细节

- **动力学模型**：采用归一化 CR3BP 方程，地球—月球质量比为 μ，航天器状态 x∈R⁶，推力通过输入矩阵 B 作用于加速度。
- **周期轨道（PO）相位控制**：
  - 参考轨道为 xd(θ)，相位 θ∈[0,1] 的标称演化速率为 1/T。
  - 引入相位控制 ω(t)，使得 dθ/dt = ω(t)/T。当 ω>1 时航天器沿轨加速，ω<1 时减速，从而实现沿轨机动。
- **拟周期轨道（QPO）相位控制**：
  - 利用 Haro-Mondelo 流映射参数化方法构造二维不变环面的生成元 K 和稳定/不稳定丛 W，满足不变性方程。

- **博弈公式**：
  - 目标函数为运行代价加终端代价，双方权重不对称（逃逸者机动性通常高于追击者）。

  - S(D) 在 D≤D₀ 时非零，D₀ 为逃逸距离阈值，且函数二阶连续可微。
- **共享时间正则化与同步**：
  - 单航天器 Sundman 变换使用各自到月球的距离 r_e、r_p 定义局部虚拟时间，导致双方未同步。
  - 引入全局共享虚拟时间 s，满足 dt = (r_e r_p)/(r_e+r_p) ds，即 dt 与 (1/r_e+1/r_p) 成反比。
  - 当任一航天器接近月球时，dt/ds 减小，节点在物理时间上局部加密，同时保证双方在相同物理时刻被评估，避免了“利用自身虚拟时间停滞获得非物理优势”的漏洞。
- **DT-DDP 算法**：
  - 在每个离散节点上，对动态和代价函数进行线性—二次近似，形成局部 min-max 二次问题。
  - 采用**主动集方法**处理推力与相位速率的硬边界约束：固定激活约束，对自由控制分量求解鞍点策略，并根据拉格朗日乘子符号释放不合适的约束。
  - 反向递推更新值函数的梯度与 Hessian，使用正则化参数 λ 保证 Hessian 正定性/负定性，并通过信任域回溯线搜索确定步长。
  - 算法（Algorithm 1）迭代进行线性化、反向、前向传播，直至控制增量收敛。

## 6. 主要结论与发现

1. **相位控制提高了机动灵活性**：通过控制参考轨道相位速率，航天器能在不显著偏离参考几何的前提下进行沿轨或横向机动，从而改善追逃效果。
2. **离散时间 DDP 具有显著计算优势**：在相同周期 NRHO 场景中，DT-DDP 比 CT-DDP 快约 30.2 倍，同时保持可比的轨迹质量。
3. **共享时间正则化至关重要**：当轨道近月距较小时，均匀时间离散收敛困难，而共享时间正则化自动加密近月节点，保持收敛并显著缩短运行时间。
4. **拟周期轨道提供额外防御自由度**：二维相位控制使逃逸者可以利用环面的横向相位转移到不同环面纤维，从而以更小的追踪误差实现逃逸。
5. **轨道几何决定追逃结果**：
   - 准 NRHO 近月通道通过放大逃逸前的微小差异，创造了更大的分离机会，但也使结果对机动时机更敏感；控制必须在进入近月通道前完成。
   - 准晕轨道距离月球较远，追逃过程更“平稳”，但最大分离受限于自身控制能力。
6. **可控制性格拉曼矩阵在近月处下降**：准 NRHO 的近月通道期间存在明显控制能力下降，进一步说明预先建立有利相遇几何的重要性。
