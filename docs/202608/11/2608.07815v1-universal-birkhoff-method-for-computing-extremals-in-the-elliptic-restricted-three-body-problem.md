## 摘要
考虑了椭圆限制性三体轨迹优化问题中有限推力极值弧的计算。通过使用快速傅里叶变换对Chebyshev-Gauss-Lobatto点上状态向量采样值进行处理，平动点轨道被近似到接近机器精度。通过将Pontryagin原理应用于最小时间和时间约束的最小推进剂问题，导出了可检查的最优性条件。这些必要条件包括最优出发点和到达点的判据。对于推进剂消耗，采用了最近开发的计算模型。该模型与推进剂的比冲无关，并随余弦项的平方倒数变化。候选最优解通过将用于轨迹优化的通用Birkhoff理论与快速、无猜测的光谱算法相结合生成。Birkhoff计算解的极值性根据Hamiltonian最小化条件和横截条件进行验证。结果表明，Birkhoff理论光谱算法无需动力学系统理论的任何辅助或初始化即可生成可验证的极值。

## Abstract
The computation of finite-thrust extremal arcs in the elliptic restricted three-body trajectory optimization problem is considered. Libration-point orbits are approximated to near-machine precision using a fast Fourier transform of the sampled values of the state vector at Chebyshev-Gauss-Lobatto points. Checkable optimality conditions are derived by applying Pontryagin's principle to minimum-time and time-constrained minimum-propellant problems. These necessary conditions include criteria for optimal departure and arrival points. For propellant consumption, a recently developed computational model is employed. This model is agnostic to the specific impulse of the propellant and varies as the inverse quadratic of a cosine term. Candidate optimal solutions are generated by combining the universal Birkhoff theory for trajectory optimization with the fast, guess-free spectral algorithm. The extremality of the Birkhoff-computed solution is validated against the Hamiltonian minimization condition and the transversality conditions. It is shown that the Birkhoff-theoretic spectral algorithm can generate verifiable extremals without any assistance or initialization from dynamical systems theory.

## 2. 论文提出的方法论：核心思想、关键技术细节、公式与算法流程

### 2.1 核心思想

将 ER3BP 中最优转移问题形式化为**端点流形（libration point orbits）之间的最优控制问题**，结合三个关键要素：

1. **Chebyshev多项式近似平动点轨道**——将数值轨道转化为近机器精度的解析表达式，从而将端点约束表示为可微的代数方程；
2. **∆prox 燃料模型**——对比冲无关的推进剂消耗代理指标；
3. **通用Birkhoff理论 + 无猜测谱算法（α-DIDO）** ——实现无需初值猜测的快速、稳定求解。

### 2.2 关键技术细节

**（1）动力学模型（Model C in [45]）**

采用Nechvile坐标系（无量纲、旋转、脉动坐标系），以真近点角 θ 为自变量：

\[
x''(\theta) - 2y'(\theta) = \partial_x\Psi(x,y,z,\theta) + \frac{u_x}{(1+e\cos\theta)^3}
\]
\[
y''(\theta) + 2x'(\theta) = \partial_y\Psi(x,y,z,\theta) + \frac{u_y}{(1+e\cos\theta)^3}
\]
\[
z''(\theta) = \partial_z\Psi(x,y,z,\theta) + \frac{u_z}{(1+e\cos\theta)^3}
\]

其中 Ψ 为伪势函数，e 为偏心率。注意控制项除以 (1+e cos θ)³——即使 e=0.0549（地月系统），忽略该项也会产生截然不同的轨迹。

**（2）∆prox 燃料模型（Isp-agnostic）**

使用 L1 范数泛函作为推进剂消耗的代理指标：

\[
\Delta^{\text{prox}}_1 := \int_{\theta_0}^{\theta_f} \frac{|u_x(\theta)| + |u_y(\theta)| + |u_z(\theta)|}{(1+e\cos\theta)^2}\,d\theta
\]

为消除 u=0 处的不可微性，采用变量替换：
- \(u_x := u_{ax} - u_{bx}\)，约束 \(u_{ax} \geq 0, u_{bx} \geq 0\)；
- 同理处理 \(u_y\)、\(u_z\)。

**（3）端点约束的代数化**

- 初始轨道（2:1 谐振 L1 Lyapunov 轨道）和最终轨道（4:1 谐振 southern NRHO）通过 CGL 网格采样 + FFT 生成 Chebyshev 插值多项式，精度达机器精度量级（~10⁻¹⁶）；
- 初始约束：\(e_1(x_0, \theta_0) = x_0 - \text{cheb}_0(\theta_0) = 0\)；
- 最终约束：\(e_2(x_f, \theta_f) = x_f - \text{cheb}_f(\beta(\theta_f)) = 0\)，其中 β 处理模 2π 的锯齿函数；
- 轨道目标约束：\(z(\theta_f) \leq z_U^f = -0.013556\) 排除 NRHO 近 perilune 高敏感区。

**（4）Pontryagin 最优性条件**

- 最小推进剂问题的 Hamiltonian：

\[
H(\lambda,x,u,\theta) := \frac{\|u\|_1}{(1+e\cos\theta)^2} + \lambda^T f(x,u,\theta)
\]

- 伴随（costate）方程由 \( \lambda' = -(\partial f/\partial x)^T \lambda\) 给出，具体为关于伪势 Ψ 的 Hessian 的线性方程；
- 控制满足**互补条件**：

\[
\mu_{\xi}^{a,b}
\begin{cases}
\leq 0 & \text{if } u_{\xi}^{a,b} = 0 \\
= 0 & \text{if } 0 < u_{\xi}^{a,b} < u_{U\xi} \\
\geq 0 & \text{if } u_{\xi}^{a,b} = u_{U\xi}
\end{cases}
\quad \forall \xi \in \{x,y,z\}
\]

- **横截条件**（出发点和到达点的最优性判据）：

\[
\lambda(\theta_0) = -\nu_0, \quad \lambda(\theta_f) = \nu_f + [0,0,\nu_{zf},0,0,0]^T
\]

- **Hamiltonian 值条件**（初末时刻）：

\[
H[@\theta_0] = \frac{\partial \bar{E}}{\partial \theta_0}, \quad H[@\theta_f] = -\frac{\partial \bar{E}}{\partial \theta_f}
\]

三者（最小推进剂、时间受限、最小时间）的具体表达略有差异。

**（5）通用Birkhoff理论（Universal Birkhoff Theory）**

- 状态变量用 a-和 b-展开表示：

\[
x_N(\theta) = x_0 B_{00}(\theta) + \sum_{j=1}^N v_j B_j^a(\theta) = \sum_{j=1}^N v_j B_j^b(\theta) + x_b B_{NN}(\theta)
\]

- Birkhoff 基函数满足特殊的插值条件（值或导数在端点为1/0）；
- 该方法**不依赖多项式基**，但可以用 Gegenbauer 多项式族实现（包括 Legendre/Chebyshev 的 Gauss/Gauss-Radau/Gauss-Lobatto 六种网格）；
- 控制函数不要求多项式展开→**无 Gibss 现象**；
- 对偶变量用 b-版本 Birkhoff 插值近似，伴随方程用谱对偶等式离散。

**（6）快速谱算法（α-DIDO）**

- 三大组件：**稳定化组件**（无猜测初始化）、**加速组件**（网格细化 N₁<N₂<...）、**精确化组件**（驱动误差至指定容差）；
- 搜索 Lyapunov 函数协调各阶段转换；
- 生成双无穷序列 \((X,\Lambda)_{N_k}^{m_k}\) 直至满足容差。

### 核心结论

1. **通用Birkhoff方法能够在ER3BP中无猜测地计算可验证的极值弧**——不需要任何动力学系统理论的初始化或辅助。

2. **Chebyshev 谱近似能够以近机器精度（~10⁻¹⁶）表示平动点轨道**——即使 N≈10,000，在现代笔记本上生成时间仅需不到 0.1 秒。

3. **∆prox 燃料模型有效消除了比冲依赖**——使推进剂计算结果更具普适性。

4. **三种场景均获得了通过全部验证的极值解**：
   - 最小时间解：TOF = 3.841000 TU，∆prox₁ 消耗 = 1.137681 VU；
   - 2π 时间受限解：∆prox₁ 消耗 = 0.619465 VU；
   - 3π 时间有界时间自由解：∆prox₁ 消耗 = 0.609603 VU（比 2π 节省约 1.6%，TOF 增加约 13%）。

5. **控制结构**：最小时间问题为纯 bang-bang 控制；时间受限/时间自由问题为 bang-off-bang 控制。所有检测中**未发现奇异弧**。

6. **Birkhoff 方法的数值特性**：
   - 条件数不随网格数 N 增长（网格无关性）；
   - 控制函数非多项式展开因此无 Gibss 现象；
   - 无需将时间区间分段（不需要 hp 配点结）。

7. **六种 Gegenbauer 网格点精度一致**——主变量一致至四位小数；对偶变量的差异在千分位量级且属于乘子非唯一性范畴。

## 7. 优点：方法或实验设计上的亮点

### 方法层面

1. **真正无猜测**：无需动力学系统理论提供初值，完全消除了"敏感性诅咒"问题。

2. **可验证性（Verifiability）**：导出了一组可以在计算后直接检查的极值性条件（横截条件、Hamiltonian 值条件、控制互补条件），使数值解的质量可以被严格认证。

3. **Isp-agnostic 推进剂模型**：使用 L1 泛函而非比冲依赖的质流率方程，使结果适用于任意推进系统。

4. **高精度端点约束**：Chebyshev 插值将数值轨道转化为近乎解析的表达式（误差 ~10⁻¹⁶），消除了端点约束近似误差对最优性的影响。

5. **无 Gibss 现象**：Birkhoff 方法中控制函数不受多项式展开限制，能够精确捕捉 bang-bang 和 bang-off-bang 不连续控制，包括极小的有限推力弧（图16a 中的小脉冲）。

6. **网格无关条件数**：即使 N 从 1000 增至 1400，算法仍稳定收敛。

7. **O(N log N) 的 FFT 加速**：使大规模网格求解在普通笔记本上即可完成。

8. **统一处理三类问题**：最小时间、时间受限、时间自由最小推进剂在同一框架下求解，只需修改 Endpoint Lagrangian 和 Hamiltonian 值条件。

### 实验设计层面

1. **双层验证结构**：内部验证（横截条件/互补条件）加外部验证（RK78 独立传播），使结果可信度高。

2. **排除敏感区域的实际工程考量**：设计 z 位置约束排除 NRHO 的 perilune 高敏感区域，体现了面向实际任务的设计意识。

**4. 敏感性/鲁棒性分析不足**：
- 未对控制上界 \(u^U\) 做参数扫描（如 \(u^U = 0.01\) 或 \(u^U = 1.0\) 时算法是否仍收敛）；
- 未研究不同平动点轨道振幅、不同谐振比对解的影响；
- 未讨论偏心率 e 变化（如 e=0（CR3BP极限）、e=0.2（太阳系极端偏心率））时算法的行为。

**5. 理论层面的局限**：
- **通用 Birkhoff 理论的推导细节被省略**——论文对 Birkhoff 基函数的构造、谱对偶等式的推导仅引用参考文献，读者如果要复现或深入理解需要另找原始文献；
- **最优性仅由一阶必要条件验证**——虽然验证了横截条件、Hamiltonian 值条件和互补条件，但未讨论解的局部最优性（二阶充分条件），也未分析是否存在多个局部极值解以及算法是否可能陷入局部次优解；
- **未分析解的拓扑结构**——如极值弧是否具有自旋/折叠等动力学系统理论关注的全局结构。

**6. 工程可实现性未充分讨论**——虽然指出 NRHO 是 NASA Gateway 的候选轨道，但未讨论推力大小（0.1 无量纲单位对应的实际推力量级）、发动机开关次数限制、最小脉冲宽度等工程约束对解的可行性的影响。

**7. 对偶变量非唯一性未深入分析**——PMP 乘子的非唯一性被提及但未给出理论解释（如是否与约束退化或奇异控制相关），这可能影响对解的物理解读。

## 9. 对读者和后续研究的启示

### 对轨迹优化研究者的启示

1. **"无猜测"是可能的**：本文展示了通过谱方法和现代最优控制理论，即使在非自治、高维动力学系统中也可以实现无初值猜测的求解。这对打破"必须用动力学系统理论或经验性初值"的传统思维有重要示范意义。

2. **可验证性是数值方法的灵魂**：论文对"极值性条件可在计算后直接检验"这一点的强调，为轨迹优化领域的数值收敛判据树立了一个良好范式——仅仅看目标函数下降或动力学残差是不够的，还应验证最优性条件的满足程度。

3. **端点约束的"解析化"是值得推广的技术**：用 Chebyshev 插值将数值轨道转化为高精度解析表达式的做法，优雅地解决了"最优控制问题中的端点流形约束"这一难点，可推广到其他轨道族和问题。

### 对工程任务设计者的启示

1. **ER3BP 解的工程价值**：在任务初步设计阶段，ER3BP 中的极值解可以作为更精细高保真模型的初始解，从而显著降低从理想模型到真实模型的迁移成本。

2. **Bang-off-bang 控制结构的实际意义**：时间受限解中出现了"off"弧（零推力段），这意味着实际任务中可以在某些时段关闭发动机，这为工程上的推进系统开关机安排提供了直接的指导。

3. **计算资源的低门槛**：在普通笔记本上完成全部计算，说明该方法可以嵌入任务设计的快速迭代循环中，无需大型计算集群。

### 后续研究的可能方向

1. **方法泛化**：将同样框架应用于真实星历模型（加入 J2、SRP、第三体摄动），或在完整 BCR4BP（双圆限制性四体问题）中扩展；
2. **多轨道族系统测试**：对 Halo、DRO、垂直 Lyapunov、L4/L5 等轨道族间的所有组合进行系统测试，建立方法的可靠统计；
3. **与现有工具的量化对比**：与 GPOPS-II、PSOPT、SNOPT 等主流工具有关同问题的性能对比；
4. **二阶最优性验证**：推导并验证 Legendre-Clebsch 条件或 Hamilton-Jacobi 充分条件，强化"最优性"而非仅"极值性"的结论；
5. **奇异弧检测的深入分析**：虽然本文未发现奇异弧，但分析在何种参数区域可能出现奇异弧是重要的理论延伸；
6. **随机鲁棒性扩展**：引入状态不确定性和控制噪声，研究鲁棒极值解的计算。

## 总体评价

本文是一篇**方法导向的高质量轨迹优化论文**。它在理论上将"Birkhoff 广义谱方法"与"ER3BP 非自治动力学"结合，在工程上解决了平动点轨道间有限推力燃料最优转移的"无猜测"求解问题。论文最大的贡献在于**证明了即使在没有初值信息的情况下，通过精心设计的谱算法和最优性条件验证体系，也能获得高质量、可认证的极值解**。其验证框架（RK78 独立传播 + 横截条件 + Hamiltonian 值条件 + 互补条件）为轨迹优化领域的数值可信度树立了标杆。主要的不足是实验场景单一、缺乏与传统方法的定量对比，以及对部分理论细节引用而未展开。总体而言，本文对深空任务轨迹初步设计具有重要的方法论参考价值，其"无猜测 + 可验证"的范式有望被推广到更广泛的航天动力学问题中。
