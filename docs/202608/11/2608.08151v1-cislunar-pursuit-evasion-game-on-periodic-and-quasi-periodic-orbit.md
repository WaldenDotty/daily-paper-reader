## 摘要
地月空间航天器运行在非线性和不稳定的环境中，这使得防御性机动规划变得困难。我们将地月空间航天器的追逃问题建模为圆型限制性三体问题中的零和微分博弈。每架航天器控制其推力和参考轨道相位，从而能够在保持接近参考轨道的同时，沿周期轨道运动并跨越拟周期环面。我们使用一种施加硬输入约束的约束离散时间微分动态规划方法求解该博弈。我们提出了一种共享时间正则化方法，以在接近月球近距离飞越时细化离散化，并同步两架航天器。周期和拟周期轨道上的数值结果表明，相位控制提高了机动灵活性，同时限制了对参考轨道的偏离。离散时间方法相比连续时间公式具有显著的计算优势。拟晕轨道与拟近直线晕轨道之间的比较表明，近距离月球飞越会带来更大的逃逸机会，但也增加了遭遇的敏感性。这些结果表明，参考轨道几何形状是地月空间防御性任务设计的重要组成部分。

## Abstract
Cislunar spacecraft operate in nonlinear and unstable environments that make defensive maneuver planning difficult. We formulate cislunar spacecraft pursuit and evasion as a zero-sum differential game in the circular restricted three-body problem. Each spacecraft controls its thrust and reference orbit phase, enabling motion along periodic orbits and across quasi-periodic tori while remaining near the reference. We solve the game using a constrained discrete-time differential dynamic programming method that enforces hard input constraints. We propose a shared time regularization to synchronize both spacecraft while refining the discretization near close lunar passages. Numerical results on periodic and quasi-periodic orbits show that phase control improves maneuvering flexibility while limiting departure from the reference orbit. The discrete-time method also provides a large computational advantage over a continuous-time formulation. Comparisons between quasi-halo and quasi-near-rectilinear halo orbits show that close lunar passages create larger escape opportunities but also increase the sensitivity of the encounter. These results show that reference orbit geometry is an important part of defensive cislunar mission design.

### 2. 方法论

#### 核心思想

论文提出一个三组分框架来解决地月空间追逃问题：

1. **参考相位控制（Reference Phase Control）**：在传统推力控制之外，为每架航天器增加参考轨道相位速率控制变量，使其能够在周期轨道上做沿轨机动、在拟周期轨道上跨越二维不变环面，而无需大幅偏离参考几何。
2. **约束离散时间博弈论微分动态规划（Constrained Discrete-Time Game-Theoretic DDP）**：计算局部鞍点策略，同时强制满足推力和相位速率硬约束。
3. **共享多智能体时间正则化（Shared Multi-Agent Time Regularization）**：保持两架航天器在物理时间上的同步，并在任一航天器接近月球时自动提高联合时间分辨率。

#### 关键技术细节

- **动力学模型**：采用圆型限制性三体问题（CR3BP）描述航天器运动，由地球和月球绕共同质心做圆轨道运动；使用归一化的旋转质心坐标系，航天器状态为 6 维（位置+速度），推力为 3 维控制输入。
- **参考轨道构建**：周期轨道（PO）为 1D 曲线（如 Lyapunov、halo、NRHO）；拟周期轨道（QPO）为 2D 不变环面，通过两步构造：① 利用流映射参数化方法（Haro & Mondelo）计算 1D 生成器及稳定/不稳定丛，通过多打靶方案与牛顿迭代求解不变性方程；② 将 1D 生成器在时间中流动，拟合并构建 2D 傅里叶级数表示。使用 Cholesky 分解和平均 Gram 矩阵进行归一化，缓解病态问题。
- **相位控制**：PO 情况下相位率控制 `ω_i(t)` 缩放参考轨道相位演化速度（`θ̇_i = (1/T) · ω_i`），大于 1 则加速、小于 1 则减速；QPO 情况下控制两个相位角 `(θ₁, θ₂)` 的速率 `ω = (ω₁, ω₂)`，分别对应纵向与横向方向。
- **零和微分博弈公式**：逃逸者最小化目标函数，追踪者最大化；目标函数包含跟踪误差惩罚、控制消耗、相位速率与标称值的偏差，以及一个关于两航天器距离的惩罚函数（幂函数形式，二阶可微）。
- **共享时间正则化**：对每个航天器独立应用 KS 变换（将 3D 笛卡尔坐标映射到 4D 虚拟空间）和 Sundman 变换（`dt = r·dτ`），但引入一个**全局共享虚拟时间** `s`，满足 `dt = (1/r_e + 1/r_p)^(-1) ds`，从而消除各航天器独立虚拟时间步长不一致的问题，避免航天器通过将自身月球距离驱向零来“暂停”自身时间从而获得不物理优势的漏洞。当任一航天器接近月球时，`dt/ds` 缩小，联合系统的物理时间步长自动细化。
- **约束离散时间 DDP**：
  - 对离散动力学和代价函数做局部线性-二次逼近，在每步形成带箱式约束的 min-max 二次规划问题。
  - 将 Tassa 等人提出的单智能体主动集 DDP 方法扩展到双玩家鞍点问题，联合求解两方自由控制，并施加相应的约束释放条件。
  - 当 `Θ_wₑwₑ` 非正定或 `Θ_wₚwₚ` 非负定时，分别添加正负正则化参数。正则化仅用于 Hessian 求逆，不扭曲真实代价函数。
  - 前向传递中采用回溯线搜索与置信域更新，通过信任域比率判断局部模型的保真度；特别地，当实际代价降低远大于模型预测（`ρ ≥ ε₂`）时拒绝该步，因为大 `ρ` 可能反映对手二次模型未能预测其真实最佳响应（是建模伪像而非真正的博弈改进）。

### 6. 主要结论与发现

1. **相位控制有效提升机动灵活性**：通过控制参考相位，航天器可以在不显著偏离参考轨道的情况下调整沿轨位置和遭遇时序，为防御性机动提供了一种代替大幅推力机动的实用手段。在 QPO 上，二维相位控制（含横向相位）使逃逸者能够通过切换到不同环面纤维来增大分离，而不必像单周期曲线那样大幅偏离参考。
2. **共享时间正则化有效解决近月数值难题**：当任一航天器接近月球时，共享时间正则化自动增加时间分辨率，避免了独立 Sundman 变换引起的时间不连续/同步问题。在近月距离很小时，正则化方案仍能保持收敛，且运行时间仅适度增长，而均匀离散化在近月点附近严重退化。
3. **离散时间 DDP 具有显著计算优势**：在周期性 NRHO 案例中，DT-DDP 比 CT-DDP 快约 30.2 倍。

- **实际应用距离**：距离实时机载应用仍有较大差距，由于线性二次近似和主动集迭代，DDP 需要在状态估计和重规划过程中反复迭代，是否有能力满足机载实时约束目前尚未清楚；论文对共享时间缩放估计误差的影响讨论也较简单（仅指出可通过状态估计和重规划来减小，但未量化其影响）。

### 研究贡献总结

本文的核心贡献可概括为一个“统一框架 + 两轮创新 + 一组发现”：**统一框架**指将 CR3BP、微分博弈、自适应正则化和参考流形控制有机结合的地月空间追逃博弈框架；**两轮创新**指算法层面的约束离散时间博弈 DDP 与共享时间正则化方法；**一组发现**指相位控制能显著提升机动灵活性、近月通道创造更大逃逸机会但伴随更高的敏感性、参考轨道几何选择是防御性任务设计的重要部分。研究为后续高保真度模型扩展（如加入通信延迟、不完美观测、扰动摄动等）建立了方法基础。
