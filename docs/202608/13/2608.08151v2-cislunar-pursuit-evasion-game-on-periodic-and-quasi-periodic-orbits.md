## 摘要
地月空间航天器运行在非线性和不稳定的环境中，这使得防御性机动规划变得困难。我们将地月空间航天器的追逐与规避问题建模为圆形限制性三体问题中的零和微分博弈。每艘航天器控制其推力和参考轨道相位，从而能够在沿周期轨道运动以及穿越准周期环面的同时保持在参考轨道附近。我们采用一种强制执行硬输入约束的约束离散时间微分动态规划方法求解该博弈。我们提出了一种共享时间正则化方法，以在细化临近月球近距离飞越附近的离散化时同步两艘航天器。周期与准周期轨道上的数值结果表明，相位控制提高了机动灵活性，同时限制了对参考轨道的偏离。离散时间方法相比连续时间公式具有很大的计算优势。准晕轨道与准近直线晕轨道之间的比较表明，近距离月球飞越会产生更大的逃逸机会，但也增加了交会的敏感性。这些结果表明，参考轨道几何结构是地月空间防御性任务设计的重要组成部分。

## Abstract
Cislunar spacecraft operate in nonlinear and unstable environments that make defensive maneuver planning difficult. We formulate cislunar spacecraft pursuit and evasion as a zero-sum differential game in the circular restricted three-body problem. Each spacecraft controls its thrust and reference orbit phase, enabling motion along periodic orbits and across quasi-periodic tori while remaining near the reference. We solve the game using a constrained discrete-time differential dynamic programming method that enforces hard input constraints. We propose a shared time regularization to synchronize both spacecraft while refining the discretization near close lunar passages. Numerical results on periodic and quasi-periodic orbits show that phase control improves maneuvering flexibility while limiting departure from the reference orbit. The discrete-time method also provides a large computational advantage over a continuous-time formulation. Comparisons between quasi-halo and quasi-near-rectilinear halo orbits show that close lunar passages create larger escape opportunities but also increase the sensitivity of the encounter. These results show that reference orbit geometry is an important part of defensive cislunar mission design.

## 二、论文提出的方法论

- **总体框架**：将追逃博弈建模为零和微分博弈，采用**约束离散时间博弈论微分动态规划（DT-DDP）** 近似求解鞍点策略，并结合**共享多智能体时间正则化**处理近月近距离飞越的数值困难。

- **核心思想与技术细节**：
  1. **参考轨道与相位控制（Phasing Control）**：
     - 对周期轨道（PO）：引入相位控制变量`ω_i(t)`，使航天器可以加速或减速沿轨运动（`θ̇_i = ω_i/T`），实现沿轨机动而不必要离开参考轨道。
     - 对准周期轨道（QPO）：利用**二维不变环面**（Fourier级数参数化）上的两个相位角`θ₁`（纵向）、`θ₂`（横向），使航天器可以**在环面表面任意移动**，比单周期轨道的机动灵活性更大。
     - 构建环面参数化：采用**流映射参数化方法**（Haro & Mondelo）计算一维生成曲线及其稳定/不稳定丛，再流传播拟合二维Fourier级数。
  2. **博弈建模**：
     - 状态向量`x = [x_e, x_p, θ_e, θ_p]`，控制向量`w_i = [u_i, ω_i]`。
     - 逃逸者最小化、追踪者最大化如下代价：跟踪误差、推力代价、相位率偏差，以及基于距离的逃逸/逼近惩罚（`S(D)`）。
     - 约束包括推力上下界和相位率上下界（硬约束）。
  3. **共享多智能体时间正则化（Shared Time Regularization）**：
     - 采用**Kustaanheimo-Stiefel（KS）变换**消除月球引力奇点（1/r²→1/r），再结合**Sundman时间变换**（`dt = r·dτ`）消除剩余奇点。
     - 关键创新：提出单一全局虚拟时间`s`，满足`dt = r_e·dτ_e = r_p·dτ_p = f_s(r_e,r_p)·ds`，其中`f_s = (1/r_e + 1/r_p)⁻¹`。这样**两艘航天器的物理时间保持同步**，避免独立正则化带来的“利用虚拟时间差获取非物理优势”的漏洞。
     - 当任一航天器靠近月球时，`dt/ds`减小，自动加密联合系统的离散化，提高近月通道处的数值分辨率。
  4. **DT-DDP算法**：
     - 将博弈离散化为离散时间零和博弈，满足离散HJI方程。
     - 在逆向传递中，对当前迭代轨迹做**线性化动力学 + 二次价值函数近似**，形成局部二次博弈。
     - 采用**活动集方法**处理控制约束：将活动分量固定在边界上，对自由分量求解联合鞍点；根据KKT乘子判断约束是否应释放。乘子为负则释放相应约束，直到满足KKT条件。
     - 在更新中使用**正则化（λ）** 保证Hessian正定性，并结合**回溯线搜索与置信域更新**决定步长；若实际代价与模型预测严重不符（ρ ≥ ε₂），则拒绝步长，以防利用对手模型的近似误差而非真实的博弈改进。
  5. **计算优势**：离散时间方法避免了连续时间DDP中反复积分微分Riccati方程的负担，计算效率显著提升。

## 六、论文的主要结论与发现

1. **相位控制提升机动灵活性**：通过控制参考轨道相位，航天器可以在保持参考轨道几何附近的条件下实现沿轨机动（PO）和环面横移（QPO），显著降低了对推力驱动的“大幅偏离参考”机动的依赖。
2. **QPO提供额外防御自由度**：在准NRHO上，逃逸者通过横向相位调整切换至不同环面纤维，在较小跟踪误差条件下实现快速分离；相比PO，QPO使航天器更快恢复到参考轨道附近。
3. **共享时间正则化的有效性**：在近月点距离很小时，自适应正则化方法仍能高效收敛，而均匀离散化方法则需要更多迭代且耗时大幅增长。有效地解决了近月通道的数值困难。
4. **离散方法的计算优势**：DT-DDP较CT-DDP加速约30.2倍，且能自然处理控制约束。
5. **轨道几何是防御任务设计的核心要素**：
   - 准NRHO利用近月通道的强非线性引力放大追逃差异，产生更大的分离（逃逸机会），但也导致更强的敏感性——关键控制动作需在临近月球前完成，进入近距离通道后操纵能力急剧下降（可控性Gramian最小特征值显著下降）。
   - 准晕轨道远离月球，引力梯度弱，机动过程更连续均匀，但分离能力受限。
   - 两者存在“逃逸能力 vs 敏感性”的固有折中，**参考轨道选择本身就是防御性任务设计的一部分**。

## 八、不足与局限

- **模型简化**：
  - 仅考虑CR3BP动力学，未纳入太阳引力、辐射压、高精度星历等摄动；实际工程任务中这些因素可能显著影响结果。
  - 假设追逃双方具有**完整状态信息**且无通信时延；实际地月空间远程通信受限，状态估计误差和通信延迟会对博弈策略产生重要影响。
- **博弈结构限制**：
  - 仅在单逃逸者vs单追踪者场景下验证，未扩展到多智能体（多追踪者/多逃逸者）情况。
  - 采用开环迭代策略，未考虑闭环鲁棒性——实际中追踪者的策略可能偏离鞍点假定。
- **实验局限**：
  - 数值实验为确定性场景下的示例性验证，缺乏大规模参数化分析（如不同初始相位差、不同质量比、不同推力约束的系统扫描）。
  - 对“逃逸成功”的判断依据是距离阈值，未深入分析后续任务可行性（如通信、在轨运行等）。
- **计算方面**：
  - DDP方法收敛到局部鞍点，**无法保证全局最优性**；在混沌动力学下，局部解对初始猜测敏感。
  - 虽然DT-DDP计算较快，但并未在超大规模/实时在线重规划场景下验证其实时性。
