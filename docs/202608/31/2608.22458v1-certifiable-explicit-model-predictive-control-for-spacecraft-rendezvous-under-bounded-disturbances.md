## 摘要
优化控制器（如模型预测控制（MPC））的两个特性限制了它们在太空飞行中的应用。在线计算时间会变化且可能超过采样周期，闭环行为也没有形式化保证。显式MPC通过计算优化问题的参数化解，用分段仿射函数的查找表替代机载优化，执行时间固定。然而，它被认为只适用于较小的预测时域，因为区域数量限制了查找表占用的内存，并且区域数量仅具有随预测时域长度指数增长的上界。本文基于二次规划参数化解和非凸可达性分析的最新进展，为Clohessy-Wiltshire动力学下的航天器交会控制器提供了完整的流程。对于该应用，可以从计算时间和内存角度构建高效的数据结构来编码控制律。此外，通过使用混合多胞体进行可达性分析，可以离线验证控制器，并获得有保证的闭环稳定性证书。在51步预测时域下，交会控制律占用10.5 MB内存，计算时间小于300纳秒。所占内存例如可放入CubeSat飞行计算机ARM9级AT91RM9200，这意味着当使用本文所示的参数化求解器和数据结构构建分区时，预测时域限制不再成立。

## Abstract
Two properties of optimization-based controllers such as model predictive control (MPC) limit their use in space flight. The online computing time varies and can exceed the sampling period, and the closed-loop behavior carries no formal guarantee. Explicit MPC, where a parametric solution of the optimization problem is computed, replaces the on-board optimization with a lookup table of piecewise-affine functions with a fixed execution time. However, it has been regarded as only applicable to small horizons, since the number of regions bounds the memory the table occupies and admits only an exponential bound in the horizon. This paper builds on recent developments in parametric solutions of quadratic programs and nonconvex reachability analysis to provide an entire pipeline for spacecraft rendezvous controllers under the Clohessy-Wiltshire dynamics. For this application, efficient data structures can be constructed to encode the control law, both from a computing time and a memory standpoint. In addition, the controller can be verified offline with a guaranteed closed-loop stability certificate by resorting to reachability analysis with hybrid zonotopes. At a 51-step horizon the rendezvous law occupies 10.5 MB and is evaluated in under 300 ns. The occupied memory would fit for instance the CubeSat flight computer ARM9-class AT91RM9200 meaning that the horizon limitation does not hold when the partition is built with the parametric solvers and data structures shown in this paper.

- **研究动机**：基于优化的控制器（如 MPC）在航天器交会中具有约束编码和燃料最优的优势，但其在线计算时间不确定、可能超过采样周期，且闭环行为缺乏形式化保证，难以在发射前完成认证。
- **现有障碍**：显式 MPC（Explicit MPC）通过离线计算参数化解，将在线优化替换为固定执行时间的查找表，被认为只适用于短预测时域，因为其分区（region）数量随预测时域呈指数级增长，导致存储占用不可接受。
- **核心问题**：能否突破显式 MPC 的“时域限制”，使其同时满足星载处理器的存储与实时性约束，并在发射前提供可证明的闭环稳定性与约束满足性？

## 2. 方法论

### 核心思想
- 将 MPC 显式解的分区构建问题与闭环验证问题分离：
  - **在线问题**：通过输入参数化（input parametrization）降低显式解的自由度，从而减小分区规模和存储；
  - **离线验证**：利用混合多胞体对闭环可达集进行**精确传播**（非过近似），并利用常数增益区域构造有限步归约条件，证明闭环最终化为单一线性反馈。
- 关键洞察：显式 MPC 的“指数爆炸”在实际中可通过参数化求解器和高效数据结构（二叉搜索树）被有效控制，且验证问题不依赖枚举所有临界区域。

### 关键技术细节

- **相对运动模型**：
  - 采用 Clohessy-Wiltshire（CW）方程线性离散模型：
    \[
    x_{k+1}=Ax_k+Bu_k+w_k,\quad w_k\in W
    \]
  - 状态为六维（位置/速度），输入为速度增量，约束为状态箱子 \(X\) 和输入箱子 \(U\)，终端集 \(X_N\)，初始散布 \(X_0\)。

- **参数化 MPC**：
  - 标准 MPC 的 condensed QP 形式为：
    \[
    \min_U \frac{1}{2}U^\top H U + x^\top F^\top U,\quad \text{s.t. } GU\le g+Sx
    \]
  - 输入序列被限制在一个低维子空间：\(U=T\eta\)，其中 \(T\) 为参数化矩阵。
  - 比较了四种参数化：
    - 标准（全自由度）；
    - 控制时域（control horizon）：仅前 \(N_u\) 步自由，其余置零；
    - Laguerre 基函数：用 \(n_L\) 个离散 Laguerre 函数表示整个输入序列；
    - 移动阻塞（move-blocking）：将输入分段保持常数。

- **常数增益区域的闭式表达式（Lemma 1）**：
  - 对任意线性输入参数化 \(T\)，定义：
    \[
    P_T=(T^\top H T)^{-1}T^\top F,\quad K_T=E_0 T P_T,\quad A_{cl}=A-BK_T
    \]
  - 则区域：
    \[
    C_T=\{x\in X: (-G_T P_T-S)x\le g\}
    \]
    （其中 \(G_T=GT,\ S\) 为约束矩阵）内，MPC 解退化为单一常数增益 \(u=-K_T x\)。
  - 该区域可由 condensed QP 数据直接矩阵乘法获得，无需枚举临界区域。

- **鲁棒不变集与有限步归约（Theorem 2 & 3）**：
  - 在 \(C_T\) 内构造最大鲁棒正不变集 \(O_W^\infty\)：
    \[
    P_j=\{x: D A_{cl}^j x\le h-\sum_{i=0}^{j-1} h_W((D A_{cl}^i)^\top)\},\quad O_W^\infty=\bigcap_{j\in\mathbb{N}_0}P_j
    \]
  - \(h_W(\cdot)\) 为扰动集 \(W\) 的支撑函数；若 \(W\) 为箱型，则 \(h_W=|\cdot|\bar w\)。
  - 若在有限步 \(k^\star\) 满足可达集 \(R_{k^\star}^W\subseteq O_W^\infty\)，则：
    - 之后所有时刻输入为固定增益 \(u_k=-K_T x_k\)；
    - 约束对所有初始条件和所有扰动序列均成立；
    - 若 \(A_{cl}\) Schur 稳定，则状态收敛到 \(A_{cl}\) 的最小鲁棒不变集。

- **混合多胞体可达性**：
  - 将参数化程序的 KKT 条件编码为混合多胞体 \(Z^\star\)，可以获得参数-优化器对的精确图表示；
  - 一步闭环传播：
    \[
    R_{k+1}^W=\Phi(R_k^W)\oplus W
    \]
    其中 \(\Phi\) 由广义交集和线性映射构成；
  - 每次相加扰动仅增加连续生成器，不增加二进制生成器，因此含扰动验证的计算复杂度与名义情况相同。

- **决策方法**：包含性检验转化为混合整数可行性问题；通过大 M 互补条件和微小裕度 \(\epsilon\) 保证严格性，返回 INFEASIBLE 即证明包含。

## 6. 主要结论与发现

- **控制时域参数化是最佳选择**：
  - 在匹配推进剂下，闭环成本比标准设计最多低 22%，离线构建速度快约 3 倍；
  - 存储优势明显：\(N=51\) 时，若存储完整预测序列，标准设计比控制时域大 24 倍；若只存储当前输入（单个仿射律），差距缩小到 15% 以内。
- **移动阻塞最弱**：粗阻塞会丧失完成任务的必要控制权限，细阻塞又不能有效缩小分区，任务完成率仅为 65/100 或更低。
- **Laguerre 基的代价不成比例**：非零极点会显著增加区域数量，但并未带来性能或合规性提升；控制时域实际上是 Laguerre 家族在极点为 0 时的退化情形。
- **显式 MPC 确实可以部署在 CubeSat 级别处理器上**：10.5 MB 的存储和亚微秒级的评估时间满足了星载资源约束，突破了“显式 MPC 仅适用于短预测时域”的传统认知。
- **可认证性**：在名义情况下，闭环可达集在 \(k^\star=4\) 步后完全进入常数增益区域的鲁棒不变集，此后闭环退化为线性系统 \(\rho(A_{cl})=0.54\)；约束满足性和收敛性由集合包含关系直接证明。
- **鲁棒性代价小**：5 倍实测扰动下，\(k^\star\) 从 4 增至 6，但二进制变量数量不变，验证计算复杂度不变；\(O_W^\infty\) 保留 \(C_T\) 体积的 33.6%。

## 7. 优点

- **直接回应领域关键质疑**：用实际存储和计算时间数据反驳了“显式 MPC 内存随预测时域指数爆炸”的笼统判断，视角更贴近工程实现。
- **常数增益区域的闭式表达**：对任意线性输入参数化都适用，使得稳定性验证中的最坏情况归约可以极低成本计算，无需枚举临界区域。
- **精确可达性分析**：混合多胞体表示 MPC 的 KKT 条件，可达集传播是精确的（既非采样内逼近，也非保守外逼近），因此验证结果是形式化证书而非概率估计。
- **扰动处理优雅**：扰动通过 Minkowski 和与支撑函数收紧进入，不增加二进制生成器数量，名义验证和鲁棒验证的计算复杂度基本相同。
- **公平比较**：所有参数化在匹配总 \(\Delta v\) 下比较，区分了“控制器激进程度”与“参数化结构”对结果的影响。
- **结构清晰**：问题定义（在线实现与离线验证）贯穿全文，理论结果（Lemma 1、Theorem 2/3）与应用结果衔接紧密。

## 8. 不足与局限

- **模型适用范围有限**：CW 模型仅适用于近圆轨道目标的近程交会；对大分离、高偏心目标需要更精确的相对运动模型，本文的理论框架虽可推广到其他线性时不变模型，但未实验验证。
- **验证条件为充分条件**：\(O_W^\infty\) 是常数增益区域 \(C_T\) 内的最大鲁棒不变集，但不是整个分段仿射闭环系统的最大不变集；\(k^\star\) 是一个上界，实际归约步数可能更小。
- **扰动上界依赖实测**：\(W\) 的选取依赖网格扫描和非线性传播残差测量，虽然带 1.25 倍裕度和 5 倍放大，但未给出如何系统化地获得保守且非空 \(W\) 的通用程序。
- **单场景验证**：只有一个低轨道交会任务，未覆盖不同轨道高度、不同初始散布形状、不同对接方向等多样场景，泛化能力未充分展示。
- **无真实硬件实测**：在线评估时间是在工作站上测量的，对星载处理器的推断基于 MIPS 估算，缺少在 AT91RM9200 或等效飞行计算机上的实际基准测试。
- **蒙特卡洛样本有限**：100 次蒙特卡洛只是辅助说明，不足以单独验证鲁棒性；好在论文主要依赖形式化集合传播，这一局限不影响证书有效性。
- **参数化选择的经验性**：虽然控制时域（\(N_u=2\)）在实验中表现最佳，但没有理论指导如何针对一般问题自动选择最优参数化。
