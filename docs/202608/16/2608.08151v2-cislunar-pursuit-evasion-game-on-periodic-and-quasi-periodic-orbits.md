## Abstract
Cislunar spacecraft operate in nonlinear and unstable environments that make defensive maneuver planning difficult. We formulate cislunar spacecraft pursuit and evasion as a zero-sum differential game in the circular restricted three-body problem. Each spacecraft controls its thrust and reference orbit phase, enabling motion along periodic orbits and across quasi-periodic tori while remaining near the reference. We solve the game using a constrained discrete-time differential dynamic programming method that enforces hard input constraints. We propose a shared time regularization to synchronize both spacecraft while refining the discretization near close lunar passages. Numerical results on periodic and quasi-periodic orbits show that phase control improves maneuvering flexibility while limiting departure from the reference orbit. The discrete-time method also provides a large computational advantage over a continuous-time formulation. Comparisons between quasi-halo and quasi-near-rectilinear halo orbits show that close lunar passages create larger escape opportunities but also increase the sensitivity of the encounter. These results show that reference orbit geometry is an important part of defensive cislunar mission design.

### 1. 核心问题与整体含义（研究动机和背景）

- **研究背景**：地月空间（Cislunar Space）正成为未来月球及行星际任务的重要区域，但其遥远和混沌的动态环境带来了新的安全挑战。与近地轨道任务不同，地月任务稀疏、依赖远距离通信，容易成为对手追逐、干扰或利用不稳定轨道动力学将目标推离标称轨道的目标。
- **核心问题**：论文研究地月空间中的航天器追逃（Pursuit-Evasion）问题。核心挑战在于：**防御方不仅需要避免被追击者拦截，还必须在规避威胁的同时保持在预定轨道附近**，以维持通信、观测、光照和站保持等任务条件。因此，问题实质是“能否在保持轨道几何的前提下规避遭遇”，而非单纯地“能否增大距离”。
- **整体含义**：该研究将参考轨道本身（而非仅作为待跟踪的轨迹）视为一种**防御性资源**——通过调整轨道相位或在准周期环面上横向移动，航天器可以重塑对抗性遭遇的几何结构，同时不偏离任务轨道。计算结果揭示了参考轨道几何（如近月通道）对防御性任务设计的重要影响。

### 2. 方法论

#### 核心思想
- 将追逃博弈建模为**圆型限制性三体问题（CR3BP）中的零和微分博弈**：逃逸者最小化其代价（增大分离距离、保持跟踪），追击者最大化该代价（减小分离距离、破坏跟踪）。
- 每个航天器的控制变量不仅包括**推力**，还包括**参考轨道相位速率**（phase-rate control），使其能够在周期轨道上沿迹调速、在准周期环面上二维移动，从而在不大幅偏离参考轨道的情况下完成机动。

#### 关键技术细节

1. **参考轨道构建**：
   - 周期轨道（PO）：如一维曲线的NRHO、halo等，相位控制沿轨道纵向调速。
   - 准周期轨道（QPO）：通过流映射参数化方法（Haro & Mondelo）计算一维生成曲线，再流传播并拟合二维傅里叶级数，形成环面参数化。相位控制包含纵向和横向两个自由度。

2. **共享多智能体时间正则化（核心创新）**：
   - 针对每个航天器独立使用Sundman变换（\(dt = r_i d\tau_i\)）导致时间不同步的问题，提出**共享虚构时间 \(s\)**，满足：
     \[
     dt = \frac{r_e r_p}{r_e + r_p} ds
     \]
   - 该方案保证两航天器在相同物理时间下同步，同时当任一航天器接近月球时自动增大联合时间分辨率，避免独立正则化产生的“时间停滞”漏洞。

3. **坐标正则化**：
   - 使用**Kustaanheimo-Stiefel（KS）变换**消除月球引力奇异性（将 \(1/r^2\) 依赖弱化为 \(1/r\)），结合Sundman变换完全移除奇点。
   - 每个航天器的状态扩展为十维：\(y = [z^T, z'^T, H, t]^T \in \mathbb{R}^{10}\)。

4. **约束离散时间博弈论DDP（DT-DDP）**：
   - 将微分博弈离散化，在每个时间节点上构造局部线性二次近似，求解受硬约束的**鞍点问题**（min-max）。
   - 采用**主动集方法（active-set method）**处理推力与相位速率的上下界约束：固定活跃分量于界上，迭代释放不满足KKT条件的约束，直到收敛。
   - 反向递推中通过正则化保证Hessian正定性，并使用**回溯线搜索与信赖域更新**（trust-region ratio）决定步长，防止发散。

5. **算法流程（Algorithm 1）**：
   - 初始化状态与控制轨迹 → 计算线性化与代价导数 → 反向递推（主动集求解鞍点、更新值函数近似）→ 前向传播（线搜索与信赖域判断）→ 迭代至收敛。

### 6. 主要结论与发现

- **相位控制提升机动灵活性**：通过控制参考相位速率，航天器能在保持靠近参考轨道的同时实现有效的沿迹或横向机动，无需依赖大幅推力偏离。准周期轨道上的横向相位控制使逃逸者能切换到不同环面纤维，在更小跟踪误差下实现快速逃逸。
- **离散时间方法计算优势显著**：DT-DDP比CT-DDP快约30倍，且在处理近月通道时数值稳定性更强。
- **共享时间正则化有效**：在多智能体场景下保持了物理时间同步，并在近月通道自动细化离散化，显著降低近月点较小时的收敛时间。
- **轨道几何是防御任务设计的关键**：
  - 准NRHO（近月通道较近）能利用月球强引力梯度放大逃逸机会，产生更大的分离距离，但结果对机动时机和进入几何敏感；控制动作必须在进入近月通道前完成，通道内控制能力急剧下降（可控性格拉姆最小特征值骤降）。
  - 准halo（远离月球）遭遇过程更平稳、跟踪误差更小，但可实现的分离距离受控制能力限制。二者存在本质权衡：**近月通道创造机会，但也增加敏感性；远月轨道更稳健，但逃逸上限更低**。
