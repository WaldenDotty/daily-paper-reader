## 摘要
地月空间飞行器运行在非线性且不稳定的环境中，这使得防御性机动规划变得困难。我们将地月空间飞行器的追击与逃避问题建模为圆形限制性三体问题中的零和微分博弈。每架飞行器控制其推力和参考轨道相位，从而能够在参考轨道附近沿周期轨道运动并穿越拟周期环面。我们使用一种强制硬输入约束的约束离散时间微分动态规划方法来求解该博弈。我们提出一种共享时间正则化方法，以在精细接近月球通道附近的离散化时同步两架飞行器。周期与拟周期轨道上的数值结果表明，相位控制提高了机动灵活性，同时限制了对参考轨道的偏离。离散时间方法相比连续时间公式还提供了巨大的计算优势。拟晕轨道与拟近直线晕轨道的比较表明，接近月球通道创造了更大的逃逸机会，但也增加了遭遇的敏感性。这些结果表明，参考轨道几何形状是地月空间防御性任务设计的重要组成部分。

## Abstract
Cislunar spacecraft operate in nonlinear and unstable environments that make defensive maneuver planning difficult. We formulate cislunar spacecraft pursuit and evasion as a zero-sum differential game in the circular restricted three-body problem. Each spacecraft controls its thrust and reference orbit phase, enabling motion along periodic orbits and across quasi-periodic tori while remaining near the reference. We solve the game using a constrained discrete-time differential dynamic programming method that enforces hard input constraints. We propose a shared time regularization to synchronize both spacecraft while refining the discretization near close lunar passages. Numerical results on periodic and quasi-periodic orbits show that phase control improves maneuvering flexibility while limiting departure from the reference orbit. The discrete-time method also provides a large computational advantage over a continuous-time formulation. Comparisons between quasi-halo and quasi-near-rectilinear halo orbits show that close lunar passages create larger escape opportunities but also increase the sensitivity of the encounter. These results show that reference orbit geometry is an important part of defensive cislunar mission design.

- **研究背景**：地月空间（Cislunar space）正成为未来月球及行星际任务的重要区域，但其距离遥远、通信受限、动力学非线性且不稳定，产生了新的安全挑战。

  - **直接拦截**：攻击方匹配目标位置与速度以实施碰撞；

- **关键约束**：航天器通常被要求保持在预定参考轨道附近（因为这些轨道具有有利的通信、观测、光照和站保持特性），因此防御机动不能大幅偏离参考轨道。传统追逃博弈理论基于二体开普勒动力学，无法直接推广到地月空间（CR3BP）的非线性不稳定环境。
- **研究意义**：将追逃博弈从二体轨道力学拓展到地月空间，为防御性任务设计提供统一框架，结合非线性轨道动力学、微分博弈论、自适应正则化和参考流形控制。

### 2. 论文提出的方法论：核心思想、关键技术细节

#### 核心思想
- 将追逃问题建模为**CR3BP中的零和微分博弈**：逃逸者最小化、追击者最大化两者之间的距离相关代价。
- **引入参考轨道相位作为额外控制变量**：航天器不仅控制推力，还控制其参考轨道相位速率，从而在不显著偏离参考轨道几何的前提下实现机动。周期轨道有一个相位控制，拟周期轨道有两个相位控制（沿环面纵向与横向）。
- **共享多智能体时间正则化**：解决独立Sundman变换导致的两航天器时间不同步问题，同时自动细化近月通道附近的数值分辨率。

#### 关键技术细节

**（1）CR3BP动力学与博弈建模**
- 采用旋转质心坐标系，航天器状态 x = [x y z ẋ ẏ ż]ᵀ ∈ R⁶，推力 u ∈ R³，质量 m；
- 追逃博弈的代价函数包含各项加权：跟踪误差、控制能耗、相位速率偏离惩罚，以及双方距离惩罚函数 S(D)（两次可微，便于数值优化）。

**（2）相位控制**
- 周期轨道：相位 θ_i ∈ [0,1]，动态为 θ̇ᵢ = (1/T)·ωᵢ(t)，ωᵢ(t) 是缩放相位演化速率的控制量；
- 拟周期轨道：由 Haro-Mondelo 流映射参数化方法构造二维不变环面，先用单参数生成器 K(θ₂) 满足流不变性条件，再经时间演化获得完整二维傅里叶级数表示；相位 θᵢ = (θᵢ,₁, θᵢ,₂) ∈ T²，两个相位速率遵循 ωᵢ = (ωᵢ,₁, ωᵢ,₂)。

**（3）KS正则化与共享时间正则化**
- 利用 Kustaanheimo–Stiefel（KS）变换从三维笛卡尔坐标映射到四维虚构空间，将月球引力奇异性从 1/r² 弱化为 1/r；
- Sundman 变换 dt = r dτ 进一步消除剩余奇异性；
- **核心创新**：引入单一全局虚构时间 s，使两航天器以共享物理时间同步推进：
  - dτₑ = rₚ/(rₑ + rₚ) ds，
  - dτₚ = rₑ/(rₑ + rₚ) ds，
  - dt = (rₑrₚ)/(rₑ + rₚ) ds = (1/rₑ + 1/rₚ)⁻¹ ds；
- 这避免了独立正则化导致的"各航天器与自己的月球副本交互"的不一致问题，防止某航天器通过将月球距离驱向零而获得非物理的时间优势。

**（4）约束离散时间博弈DDP（DT-DDP）**
- 将连续博弈离散化（在虚构时间 s 上均匀采样，得到非均匀物理时间步）；
- 在每次反向传播中进行线性二次近似；
- 将活动集方法扩展至零和博弈：固定控制分量在上下界，对自由分量求解鞍点，通过拉格朗日乘子判定活动集释放条件；
- 加入正则化项确保 Hessian 正定性；用回溯线搜索与信赖域比 ρ 控制步长，ρ 过大（≥ε₂）时拒绝步长（因为对手模型的失效不可靠）；
- 正向传播采用缩放的 feedforward 控制更新与反馈增益。

**（5）算法流程（Algorithm 1）**：初始状态轨迹 → 反复（线性化 → 反向传播求解约束鞍点 → 正向传播与信赖域线搜索）直至收敛。

### 6. 论文的主要结论与发现

- **相位控制有效性**：受控相位速率能在保持参考轨道附近的同时增加分离距离，是大幅推力机动的实用替代方案。拟周期轨道的第二个相位控制自由度（横向环面相位）能改变局部遭遇几何，创造一维曲线无法实现的逃逸机会。
- **离散时间法计算效率优势显著**：DT-DDP 比 CT-DDP 快约 30.2 倍；共享时间正则化在近月点距离很小时仍能保持收敛，而均匀离散化则严重退化。
- **近月通道的影响是双刃剑**：拟NRHO（近距离掠月）相比拟晕轨道创造了更大的逃逸机会（利用月球的强非线性引力放大先前建立的相对状态差异），但同时也增加了遭遇的敏感性——追击者在有利的进入几何下也能更快缩短距离。关键控制动作必须**在进入近月通道之前**完成，进入后控制权限急剧下降。
- **轨道几何设计是防御性任务设计的重要组成部分**：选择不同的参考轨道族直接决定了追逃博弈中可实现的分离能力与策略时间结构。

### 7. 优点

- **方法创新性强**：
  - 将相位控制引入追逃博弈，在"保持参考轨道"与"机动灵活性"之间架起桥梁；
  - 共享多智能体时间正则化解决了独立 Sundman 变换的时间同步难题，理论推导清晰（类比 Heggie 全局正则化，但应用于不同目的）；
  - 将活动集 DDP 扩展到零和博弈鞍点求解，正确处理硬输入约束。
- **实践相关性强**：与实际任务关注点（NRHO、近月通道、参考轨道保持）紧密结合，结论对防御性任务设计有直接指导意义。
- **计算效率高**：在保持数值精度的同时大幅提升求解速度，具备在线重规划的潜力（5 次重规划）。
- **分析的深入性**：不仅报告数值结果，还通过可控性 Gramian 的谱分析解释了近月通道导致控制权限下降的机理，给出了策略时间结构的深刻洞见。

### 8. 不足与局限

- **模型理想化**：假设双方完美知道对方状态（无测量噪声、无通信延迟），实际地月空间通信条件差，这个假设是较强限制；
- **动力学简化**：仅考虑 CR3BP，未纳入太阳引力、太阳光压、月球非球形引力等高保真摄动；
- **局部性限制**：DDP 是局部方法，只能找到局部鞍点，不保证全局最优。在强非线性近月通道附近，局部二次近似的可靠性可能受限；
- **参数覆盖有限**：缺乏对初始条件（相位差、轨道面偏差）、推力限制范围、权重矩阵选择等的系统敏感性分析；
- **单一攻防场景**：只考虑一对一追逃，未涉及多追击者/多逃逸者协作或通信对抗场景；两种航天器配置相同（无不同推进能力对比场景的系统研究）；
- **可扩展性问题**：虽然提出理论可以推广到更高维环面，但实际仅在二维拟周期轨道上验证，更高维情况下的数值可行性尚不明确。
