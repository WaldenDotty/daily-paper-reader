## 摘要
地月空间航天器运行在非线性且不稳定的环境中，这使得防御性机动规划变得困难。我们将地月空间航天器的追击与逃避问题建模为圆形限制性三体问题中的零和微分博弈。每个航天器控制其推力和参考轨道相位，从而能够沿周期轨道运动，并在保持接近参考轨道的同时跨越准周期环面。我们使用一种强制硬输入约束的约束离散时间微分动态规划方法求解该博弈。我们提出了一种共享时间正则化方法，以在细化接近月球经过时的离散化同时同步两个航天器。周期和准周期轨道上的数值结果表明，相位控制提高了机动灵活性，同时限制了对参考轨道的偏离。离散时间方法相比连续时间公式具有较大的计算优势。准晕轨道与准近直线晕轨道之间的比较表明，近距离月球经过会产生更大的逃逸机会，但也增加了遭遇的敏感性。这些结果表明，参考轨道几何形状是地月空间防御性任务设计的重要组成部分。

## Abstract
Cislunar spacecraft operate in nonlinear and unstable environments that make defensive maneuver planning difficult. We formulate cislunar spacecraft pursuit and evasion as a zero-sum differential game in the circular restricted three-body problem. Each spacecraft controls its thrust and reference orbit phase, enabling motion along periodic orbits and across quasi-periodic tori while remaining near the reference. We solve the game using a constrained discrete-time differential dynamic programming method that enforces hard input constraints. We propose a shared time regularization to synchronize both spacecraft while refining the discretization near close lunar passages. Numerical results on periodic and quasi-periodic orbits show that phase control improves maneuvering flexibility while limiting departure from the reference orbit. The discrete-time method also provides a large computational advantage over a continuous-time formulation. Comparisons between quasi-halo and quasi-near-rectilinear halo orbits show that close lunar passages create larger escape opportunities but also increase the sensitivity of the encounter. These results show that reference orbit geometry is an important part of defensive cislunar mission design.

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 核心思想

论文将地月空间追击-逃避问题建模为**圆型限制性三体问题（CR3BP）中的零和微分博弈**。两个航天器分别扮演逃逸者（Evader）和追踪者（Pursuer），逃逸者希望增大与追踪者的距离，追踪者则希望最小化该距离，同时双方都必须保持在参考轨道附近以维持任务效能。

### 2.2 关键技术创新

1. **参考轨道相位控制（Reference Orbit Phasing）**：
   - 将参考轨道相位速率作为额外的控制变量，允许航天器沿周期轨道（PO）进行沿轨机动，或沿准周期轨道（QPO）的二维不变环面进行横向移动。
   - 这使得航天器可以**在不显著偏离参考轨道几何的前提下**改变与对手的遭遇形态，将参考轨道本身转化为一种防御资源。

2. **约束离散时间博弈论DDP（Constrained Discrete-Time Game-Theoretic DDP）**：
   - 将连续时间微分博弈离散化，采用**离散时间差分动态规划（DT-DDP）**求解。
   - 将单智能体active-set DDP方法[24]扩展到**两人鞍点问题**：在反向传播中联合求解双方的自由控制量，并分别针对最小化者（逃逸者）和最大化者（追踪者）执行合适的约束释放条件。

3. **共享多智能体时间正则化（Shared Multi-Agent Time Regularization）**：
   - 将Sundman变换推广到多智能体场景，引入单一全局虚拟时间 \(s\)，满足：
     \[
     \frac{dt}{ds} = \frac{r_e r_p}{r_e + r_p}
     \]
   - 该方案**保持双方在物理时间上的同步**，避免独立正则化导致某一飞行器通过趋近月球来“冻结”自身物理时间、获得非物理优势的漏洞。
   - 当任一航天器接近月球时，系统自动增加联合时间分辨率，使离散化在近月通道附近自动加密。

### 2.3 求解流程

算法核心是一个DDP迭代过程：
- **前向传播**：在当前轨迹上仿真生成候选轨迹；
- **反向传播（Backward Pass）**：在各节点求解受约束的局部线性二次鞍点问题，利用KKT条件更新active set，得到前馈增益和反馈增益；
- **可信域线搜索与正则化**：通过信任域比率 \(\rho\) 判断局部模型保真度并调整正则化参数 \(\lambda\)，确保收敛。

## 6. 论文的主要结论与发现

1. **相位控制显著提升机动灵活性**：相比仅用推力，相位控制使航天器能够在贴近参考轨道的同时改变遭遇几何，降低追踪误差。
2. **准周期轨道提供额外防御自由度**：横向环面相位（\(\theta_2\)）使逃逸者得以切换至不同环面纤维而非依赖大幅轨道偏离，更快恢复至参考轨迹。
3. **离散时间DDP具有明显计算优势**：在周期NRHO场景中实现约30.2倍加速。
4. **共享时间正则化维持同步并提升鲁棒性**：在近月点极小时仍能有效收敛，而非正则化方案的迭代次数和耗时激增。
5. **近月通道是一把双刃剑**：准NRHO因靠近月球而获得更强的引力放大效应、产生更大的分离距离，但带来了显著的**控制权丧失**（可控性格拉姆矩阵最小特征值骤降）和更高的遭遇敏感性；准晕轨道虽分离能力较弱，但博弈过程更均匀、控制策略更平滑。
6. **轨道几何是防御性任务设计的关键因素**：策略需在进入近月通道前确定遭遇几何，近月通道负责放大已有的相对状态差异。
