## 摘要
研究了椭圆限制性三体轨迹优化问题中有限推力极值弧段的计算。通过在切比雪夫-高斯-洛巴托点上对状态向量采样值进行快速傅里叶变换，平动点轨道被近似到接近机器精度。通过将庞特里亚金原理应用于最小时间和时间约束下的最小推进剂问题，导出了可检验的最优性条件。这些必要条件包括最优出发点和到达点的判据。对于推进剂消耗，采用了一种最近开发的计算模型。该模型与推进剂比冲无关，并随余弦项的平方倒数变化。通过将用于轨迹优化的通用Birkhoff理论与快速、无猜测的谱算法相结合，生成候选最优解。针对哈密顿量最小化条件和横截条件，验证了Birkhoff计算解的极值性。结果表明，基于Birkhoff理论的谱算法可以在无需动力学系统理论任何辅助或初始化的情况下生成可验证的极值曲线。

## Abstract
The computation of finite-thrust extremal arcs in the elliptic restricted three-body trajectory optimization problem is considered. Libration-point orbits are approximated to near-machine precision using a fast Fourier transform of the sampled values of the state vector at Chebyshev-Gauss-Lobatto points. Checkable optimality conditions are derived by applying Pontryagin's principle to minimum-time and time-constrained minimum-propellant problems. These necessary conditions include criteria for optimal departure and arrival points. For propellant consumption, a recently developed computational model is employed. This model is agnostic to the specific impulse of the propellant and varies as the inverse quadratic of a cosine term. Candidate optimal solutions are generated by combining the universal Birkhoff theory for trajectory optimization with the fast, guess-free spectral algorithm. The extremality of the Birkhoff-computed solution is validated against the Hamiltonian minimization condition and the transversality conditions. It is shown that the Birkhoff-theoretic spectral algorithm can generate verifiable extremals without any assistance or initialization from dynamical systems theory.

## 二、方法论

### 1. 动力学模型与坐标系
- 使用 **Nechvile 坐标系**（无量纲、旋转、脉动坐标系），以**真近点角 θ** 为自变量，规避了 ER3BP 非自治性带来的部分困难。
- 航天器动力学方程为带推力控制项的三体运动方程，控制量除以立方余弦项（1 + e cos θ)³，若忽略该因子即使对很小的偏心率也会产生显著偏差。

### 2. 推进剂消耗模型（∆prox 模型）
- 采用**不依赖比冲（Isp-agnostic）**的 L1 泛函作为推进剂消耗指标：

  \[
  \Delta\mathrm{prox}_1 = \int_{\theta_0}^{\theta_f} \frac{|u_x|+|u_y|+|u_z|}{(1+e\cos\theta)^2} d\theta
  \]

- 该模型在 u=0 处不可微。通过变换 u = ua − ub（其中 ua ≥ 0, ub ≥ 0）消除不可微性，使问题可**一步求解**，无需同伦/延拓方法。

### 3. 边界轨道的 Chebyshev 逼近
- 平动点轨道通过微分校正 + 高精度 Runge-Kutta 方法生成后，使用 **Chebfun** 在 Chebyshev-Gauss-Lobatto（CGL）节点上采样，构造 Chebyshev 多项式插值（FFT 加速），将轨道表示为解析形式的 e1(x0,θ0)=0 和 e2(xf,θf)=0 代数约束。
- 切比雪夫逼近误差接近**机器精度**（~10⁻¹⁶）；L1 Lyapunov 轨道需 N=308，NRHO 因近月点速度尖峰需 N=9778，但 Chebfun 生成时间不足 0.1 秒，内存仅约 0.08 MB。

### 4. 最优控制问题形式化
- 统一表述为 Bolza 型最优控制问题（式 23），包含：
  - 端点流形约束（起始/目标轨道）
  - 目标点 z 位置约束（排除 NRHO 近月点高灵敏度区域，z(θf) ≤ −0.013556）
  - 时间窗口约束（0 < θf − θ0 ≤ ∆θU）
  - 控制幅值约束（0 ≤ ua, ub ≤ uU）
- 考虑三类问题：**最小时间**、**时间受限最小推进剂**（TOF ≤ 2π）、**时间边界时间自由最小推进剂**（TOF ≤ 3π）。

### 5. 庞特里亚金原理与最优性条件
- 构造 Pontryagin 哈密顿量、增广哈密顿量（引入 path covectors μ 和端点 Lagrangian），推导**可计算验证的条件**：
  - **伴随方程**（costate dynamics）：显式给出六个成本变量的微分方程
  - **横截条件**（transversality conditions）：λ(θ0) = −ν0，λ(θf) = νf + [0,0,νzf,0,0,0]ᵀ，以及哈密顿量值条件 H[θ0] 和 H[θf] 的表达式
  - **控制切换结构**（complementarity conditions）：给出 bang-bang 和 bang-off-bang 控制的必要条件
  - **νzf、νθ 的补松弛条件**（约束激活判定）
- 这些条件被框出并作为后续数值验证的“检查项”。

### 6. 通用 Birkhoff 理论与谱算法
- **Universal Birkhoff 理论**：通过 a-和 b-两种 Birkhoff 展开同时逼近状态与伴随变量，构造 Birkhoff 基函数，满足特定插值条件。该理论不依赖多项式基函数，具有网格无关条件数（condition number）的优点。
- **谱算法**（由 DIDO 的 α 版本实现）：结合稳定化（guess-free）、加速和精度三个子算法，生成双重无穷序列 (X,Λ)_N^m，在 N 增长中逐步收敛。
- **网格选择**：对比六种 Gegenbauer 网格（LGL/LGR/LG/CGL/CGR/CG），结果表明在原始变量上六种网格精度一致（四位小数相同），双变量（ν0）差异也仅为万分之几。最终选择 **Chebyshev 网格**，因为它可以用单行代码生成、支持 FFT 加速（O(N log N)），且不存在 Legendre 网格的计算复杂度问题。
- **关键优势**：无吉布斯现象（即使控制量有不连续跳变），无需传统 hp 法那样分割时间区间。

## 八、不足与局限

- **实验覆盖范围有限**：仅研究了单一任务构型（L1 Lyapunov → L2 南部 NRHO），未覆盖其他类型平动点轨道（halo、DRO、蝴蝶轨道等）、其他质量比（如太阳-地球系统）或不同偏心率取值。
- **未与其他优化算法直接对比**：没有在同一问题基准上对比 SQP、直接配点、间接打靶或传统 PS 方法的精度与耗时，难以量化和定位其相对优势。
- **奇异弧问题未处理**：文中仅声明“未检测到奇异弧”，未给出奇异弧的检测条件或应对策略。对于更一般的最优控制问题（如 ∆prox2 模型或不同推力幅值），奇异弧可能出现。
- **无理论收敛性证明的完整推导**：论文引用了 Universal Birkhoff 理论在其他文献中的收敛性结论，但对该理论在含约束最优控制问题（含路径约束与端点流形）中的理论保证未给出具体推导。
- **数值误差的量级**：横截条件和哈密顿量值条件的满足精度在 10⁻³ 量级，虽已满足工程需求，但距离机器精度仍有一定差距（文中仅以“合理精度”描述）。
- **对 Isp-agnostic 模型的适用边界**：∆prox1 是实际推进剂消耗的“代理”指标，与真实质量消耗之间的关系依赖于推力器配置；实际应用中还需结合具体推进系统进一步折算。
