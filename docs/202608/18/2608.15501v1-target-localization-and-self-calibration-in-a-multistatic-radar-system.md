## 摘要
多基地雷达系统中的目标定位，其中多个接收器协同工作以提高目标定位精度，在许多应用中具有广泛用途，包括协同同时定位与建图（SLAM）和自主机器人网络。这些应用中的一个关键挑战是由于平台移动性导致的雷达接收器位置和姿态（位姿）的不确定性。本文通过推导执行双基地距离和方位测量的多基地雷达系统的克拉美-罗下界（CRLB），研究了目标定位和接收器姿态估计方面可实现的改进。我们提出了一种交替加权最小二乘算法，该算法联合优化目标和接收器参数。蒙特卡洛模拟表明，在低到中等噪声水平下，该算法的性能接近CRLB。

## Abstract
Target localization in a multistatic radar system, where multiple receivers cooperate to improve target positioning accuracy, has many applications, including cooperative simultaneous localization and mapping (SLAM) and autonomous robot networks. A key challenge in these applications is the uncertainty in the position and orientation (pose) of the radar receivers due to platform mobility. This work investigates the achievable improvements in both target localization and receiver pose estimation by deriving the Cramer-Rao lower bound (CRLB) for a multistatic radar system performing bistatic range and bearing measurements. We propose an alternating weighted least-squares algorithm that jointly optimizes target and receiver parameters. Monte Carlo simulations demonstrate that the algorithm performance approaches the CRLB for low to moderate noise levels.

- 论文聚焦于**多基地雷达系统中的联合目标定位与接收机自校准问题**。多基地雷达通过多个接收机协同观测目标，可提升定位精度，广泛应用于协同 SLAM、自主机器人网络等场景。
- 实际部署中，接收机往往是移动平台（车辆、无人机、舰载平台），其自身位置和姿态（pose）存在不确定性（通常来自 GNSS 和 IMU 的先验估计误差）。这种不确定性会直接降低目标定位精度，并使各接收机难以在统一全局坐标系下融合观测数据。
- 因此，核心任务是在已知发射机位置、但接收机位姿有噪声的前提下，**同时估计目标位置与接收机位姿**，实现目标定位与接收机自校准。该问题本质上是高度非线性、非凸的联合估计问题。

## 2. 论文提出的方法论

- **核心思想**：构建联合估计的加权最小二乘目标函数，采用**交替优化**策略，将联合问题分解为“接收机位姿更新”和“目标位置更新”两个子问题，并在每次迭代中对非线性测量模型进行**一阶泰勒线性化**，从而得到闭式解，避免高复杂度全局优化。
- **测量模型**：
  - 双基地距离：`r_ij = ||u_j - t|| + ||u_j - s_i||`
  - 方位角：`theta_ij = atan2(u_jy - s_iy, u_jx - s_ix) - phi_i`
  - 观测噪声假设为高斯，接收机位姿先验亦为高斯（方位误差用 Von Mises 分布近似）。
- **CRLB 推导**：
  - 构建双基地距离和方位角测量向量、接收机位置/方位向量、目标位置向量的联合高斯分布。
  - 推导对数似然函数关于未知参数（目标位置向量 u 和接收机位姿向量 ω）的 Fisher 信息矩阵（FIM）。
  - FIM 的块结构为 `[[X, Y], [Y^T, Z + Q_omega^{-1}]]`，其中 X、Y、Z 由测量噪声协方差和 Jacobian 矩阵构建。
  - 利用分块矩阵求逆公式得到目标位置 CRLB 和接收机位姿 CRLB：
    - `CRLB(u) = (X - Y(Z + Q_omega^{-1})^{-1}Y^T)^{-1}`
    - `CRLB(ω) = (Z + Q_omega^{-1} - YX^{-1}Y^T)^{-1}`
- **交替加权最小二乘算法（Algorithm 1）**：
  1. 初始化：利用发射机位置、接收机初始位姿先验和测量值，通过射线-椭圆交点法获取每个目标位置的初始均值。
  2. 迭代循环：
     - **子问题 1（接收机更新）**：固定目标位置，对每个接收机 i，对测量残差和位姿先验残差做线性化（围绕当前位姿估计），构建 Gauss-Newton 更新：`ω_i^(k+1) = ω_i^(k) - (G_i + λ_i I)^{-1} g_i`，其中 `G_i` 为 Hessian 近似，`g_i` 为梯度。
     - **子问题 2（目标更新）**：固定接收机位姿，对每个目标 j，线性化目标位置的观测残差，执行 `u_j^(k+1) = u_j^(k) - (G_j + λ_j I)^{-1} g_j`。
  3. 重复直到接收机和目标位置更新的最大变化量小于容差。
- 算法复杂度：每次迭代的 Jacobian 计算为 O(MK)，更新步骤为 O(M+K)（Hessian 维度为 2×2 或 3×3），计算效率高，并支持后续分布式实现。
