## 摘要
六自由度位姿估计是自主交会与近距离操作中的关键任务。在目标未知的情况下，该任务变得具有挑战性，因为它需要与目标形状模型的重建相结合。在本文中，我们提出了一种新颖的框架，用于对未知航天器目标进行单次形状和位姿估计。给定单张图像，我们首先重建目标的三维形状模型，然后通过学习稠密的2D-3D对应关系来估计相对的六自由度位姿。图像特征使用冻结的DINOv3视觉Transformer提取，而几何特征则使用可训练的动态图卷积神经网络编码器从重建的点云中计算。一种双流Transformer匹配器通过交替的自注意力和交叉注意力来优化描述符，生成软对应关系，并将其传递给透视n点（Perspective-n-Point）求解器进行位姿恢复。我们在SPE3R数据集上评估了该方法，并将FoundationPose作为当前最先进能力的代表性基线。结果表明，仅使用单张图像和重建的几何结构，位姿估计即实现了0.157度的平均指向误差，展现了对未见航天器的强大泛化能力。

## Abstract
6-DoF pose estimation is a critical task in autonomous rendezvous and proximity operations. In the case of an unknown target, this task becomes challenging as it shall be paired with the reconstruction of the target shape model. In this article, we propose a novel framework for single-shot shape and pose estimation of unknown spacecraft objects. Given a single image, we first reconstruct a 3D shape model of the target, then estimate the relative six-degrees-of-freedom pose by learning dense 2D-3D correspondences. The image features are extracted using a frozen DINOv3 vision transformer, while the geometric features are computed from the reconstructed point cloud using a trainable dynamic graph convolutional neural network encoder. A dual-stream transformer matcher refines descriptors through alternating self- and cross-attention, producing soft correspondences that are passed to a Perspective-$n$-Point solver for pose recovery. We evaluate the method on the SPE3R dataset and consider FoundationPose as a representative baseline for current state-of-the-art capabilities. Results show reliable pose estimates achieving 0.157 degrees mean pointing error using only a single image and reconstructed geometry, demonstrating strong generalization to unseen spacecraft.

### 2. 论文提出的方法论：核心思想与关键技术细节
- **整体流程**：输入单张RGB图像 → 利用 **Hunyuan-3D-2.0**（单视图生成模型）重建目标三维网格 → 分别提取2D和3D特征 → 通过双流Transformer匹配器学习稠密2D-3D对应 → 经EPnP+RANSAC求解位姿。
- **关键技术细节**：
  - **2D特征提取**：使用**冻结的DINOv3 ViT-B/16**，输出网格状patch描述子（768维），经线性投影为256维；并附加轻量级显著性评分头，用于关键点选择（通过前景掩码约束在目标上）。
  - **3D特征提取**：从重建网格均匀采样1024个点，输入**动态图卷积神经网络（DGCNN）**，构建k=20的近邻图，经4个EdgeConv层得到每个点的256维嵌入，初始化随机但随匹配器联合训练。
  - **跨模态匹配器**：基于Transformer的双流编码器-解码器（类似SuperGlue），对2D/3D描述子加入位置编码后，交替进行自注意力和交叉注意力（4层），输出余弦相似度矩阵S，经**Sinkhorn归一化**得到软对应矩阵P（大小N×M，N为2D关键点数，M为3D点数）。
  - **损失函数**：利用已知相机位姿（监督训练），构造软标签P^gt（基于3D点投影到2D的欧氏距离，高斯加权softmax），优化以下四项：
    - 软对应损失 L_soft（交叉熵）
    - 期望点云损失 L_xyz（预测软匹配加权和的3D点与目标3D点L2误差）
    - 重投影损失 L_reproj（将预测软匹配3D点投影回2D与观测2D点的距离）
    - 互近邻损失 L_mnn（双向匹配一致性）
    总损失 L_sup = λ_soft L_soft + λ_xyz L_xyz + λ_mnn L_mnn + λ_reproj L_reproj，权重为(1.0, 1.0, 0.5, 0.01)。
  - **位姿求解**：取软矩阵P中置信度高的候选对应，通过EPnP（Efficient PnP）配合RANSAC（200次迭代）得到初始位姿，再用Levenberg-Marquardt最小化重投影误差进行精细优化。

- **输入处理技巧**：对目标在图像中占比较小的情况，采用**边界框裁剪并放大**至256×256，提高特征提取质量。

- **对比基线**：**FoundationPose**（NVIDIA），当前最先进的零样本6D位姿估计器，但需要RGB+深度+网格作为输入。本文为其提供真实CAD网格或重建网格，并使用从真值渲染的深度图（理想条件），因此FoundationPose作为“最优性能上界”而非公平对比。
- **实验配置**：
  - **地面真值（GT）评估**：用原始CAD网格估计位姿，作为DreamSat-Pose和FoundationPose的上界。
  - **重建（Recon）评估**：用Hunyuan-3D-2.0从单图重建的网格估计位姿。分两种子设置：每测试卫星1张图（7000张）和每测试卫星100张图（700张，平衡黑白背景）。

- **评估指标**：
  - 指向误差（LOS误差）：估计平移向量与真值平移向量之间的角度。

  - 重建质量指标：3D体交并比（IoU）、倒角距离（CD）、豪斯多夫距离（HD）。
  - 帧模糊处理：由于重建网格的物体坐标系定义存在符号歧义，评估时对所有有效右手系翻转取最小误差。

### 6. 论文的主要结论与发现
- DreamSat-Pose能在**仅单张RGB图像、无深度、无先验模型**条件下，实现有意义的6-DoF位姿估计，平均指向误差0.157°，旋转误差中位数61.89°（使用重建网格）。
- 重建的三维网格可有效替代真实CAD作为几何代理，但旋转精度仍受限于重建质量、物体对称性和帧模糊问题。

- 3D重建质量与最终位姿精度之间**未发现明显相关性**，提示瓶颈更多在匹配和对称性处理。

### 7. 优点
- **方法创新**：将位姿估计分解为“重建+匹配+几何求解”，融合了生成式3D与判别式2D-3D匹配，避免了直接位姿回归对大量标注的依赖。
- **泛化能力**：通过冻结DINOv3（大模型视觉特征）和可训练的DGCNN+匹配器，实现了对未见航天器的泛化，无需目标级微调。
- **单目友好**：完全不依赖深度或立体视觉，符合实际太空任务中SWaP（尺寸、重量、功耗）限制。
- **损失函数设计**：兼顾软对应、3D空间对齐、2D重投影一致性，训练稳定；使用Sinkhorn归一化产生可微的软匹配。
- **帧模糊处理**：显式考虑重建物体坐标系符号歧义，避免因坐标系定义不同而错误惩罚。
- **模块化**：各组件（重建、特征提取、匹配、PnP）可独立替换升级。

### 8. 不足与局限
- **实时性不足**：端到端推理总耗时（重建35-40s + 匹配0.034s）远不能满足实时闭环控制需求。快速变体妥协质量。
