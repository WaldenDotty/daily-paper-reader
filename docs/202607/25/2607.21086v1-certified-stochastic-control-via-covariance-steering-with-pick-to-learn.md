## 摘要
我们提出了CS-P2L，一个将协方差引导（CS）与Pick-to-Learn（P2L）元算法相结合的框架，用于在高保真随机模拟器上进行认证控制器综合。该方法在模拟器运行中反复评估策略，利用最坏情况违规收紧替代约束，并在给定置信水平下提供基于压缩的关于真实违规概率的概率性保证。在一个重力不确定的航天器动力下降问题中，CS-P2L在600次运行中认证的违规边界为4.9%，而单独的协方差引导则低估了约两倍的违规率。

## Abstract
We present CS-P2L, a framework coupling covariance steering (CS) with the Pick-to-Learn (P2L) meta-algorithm for certified controller synthesis over high-fidelity stochastic simulators. The method iteratively evaluates policies on simulator rollouts, tightens surrogate constraints using the worst-case violations, and provides compression-based probabilistic guarantees on the true violation probability given a confidence level. On a spacecraft powered-descent problem with uncertain gravity, CS-P2L certifies a violation bound of 4.9\% with 600 rollouts, whereas standalone covariance steering underestimates the violation rate by roughly a factor of two.

- **问题**：在安全关键控制系统中，高保真随机模拟器能精细刻画复杂动态与环境不确定性，但直接在模拟器上综合具有形式化保证的控制器是难以处理的。传统做法是在简化替代模型上设计策略，再通过蒙特卡洛（MC）模拟验证，但MC仅给出违规概率的点估计，缺乏将模拟失败反馈回策略改进的机制，且无法提供概率性保证。
- **背景**：现有方法如情景方法、迭代情景优化、PAC-Bayes控制、神经超鞅证书等各有局限：要么要求凸性、要么需嵌入复杂动力学、要么只保证期望而非单策略违规概率、要么需状态空间离散化。协方差引导（CS）通过凸规划合成满足机会约束的控制器，但通常基于线性化替代模型，忽略了替代-模拟器间的失配。
- **本文目标**：提出CS-P2L框架，将协方差引导与Pick-to-Learn（P2L）元算法结合，在高保真连续时间随机模拟器上，以可计算的方式合成并认证一个零阶保持的反馈-前馈控制器，使其违规概率在给定置信度下有上界。

## 2. 方法论：核心思想、关键技术细节、算法流程

- **核心思想**：
  - 将控制器设计问题分解为两层：内层在简化替代模型（线性化、离散化的协方差引导问题）上求解，外层通过P2L循环，在真实模拟器上评估策略，挑选最严重违规的轨迹，用于收紧替代问题的约束，从而缩小替代-模拟器失配。最终输出的政策与一个“压缩集”相关联，基于压缩理论给出违规概率的上界。
- **关键技术细节**：
  1. **模拟器定义**：连续时间SDE，含有不确定时间不变参数，零阶保持控制，返回精细网格的状态轨迹和控制序列。
  2. **规格说明**：可达-避免规范，包括安全状态约束（多个半空间）、控制幅度约束、终端椭圆域约束。违规概率定义为一次部署中随机实现违反规范的概率。
  3. **替代协方差引导（CS）问题**：
     - 通过线性化、离散化得到LTV系统方程，引入虚拟控制参数处理线性化不可行性。
     - 状态均值和协方差演化被凸化（使用变量变换 \(U_k = K_k P_k\) 和舒尔补）。
     - 安全约束和终端约束被转化为凸不等式（使用高斯分位数和χ²分布）。
     - 控制约束通过特征值线性化处理。
     - 求解过程使用连续凸规划收敛到动态可行解。
  4. **Pick-to-Learn (P2L) 外层循环（算法2）**：
     - 初始化：基于初始配置求解CS得到初始策略，在固定数据集ZN上评估。
     - 迭代：只要存在未加入压缩集的轨迹违反规范，就选择违规最严重的轨迹（按定义的违规度量）加入压缩集，然后使用配置算法更新替代问题参数（收紧安全边界、控制上限、终端协方差），重新求解CS并重新评估所有轨迹。
     - 终止条件：所有不在压缩集中的轨迹都满足规范。返回最终策略与压缩集。

     - 基于压缩理论，输出策略的违规概率上界 \(\bar{\varepsilon}(|T|, \delta, N)\) 由压缩集大小、总数据点数、置信度δ唯一确定，且以至少1-δ的概率成立。
