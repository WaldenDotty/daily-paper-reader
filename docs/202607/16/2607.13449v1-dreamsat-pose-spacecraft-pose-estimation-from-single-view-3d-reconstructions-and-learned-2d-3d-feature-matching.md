## 摘要
6自由度姿态估计是自主交会与近距离操作中的关键任务。在目标未知的情况下，该任务因需与目标形状模型重建相结合而变得具有挑战性。本文提出了一种针对未知航天器物体的单次形状与姿态估计的新框架。给定单张图像，我们首先重建目标的三维形状模型，然后通过学习密集的2D-3D对应关系来估计相对六自由度姿态。图像特征使用冻结的DINOv3视觉Transformer提取，而几何特征则使用可训练的动态图卷积神经网络编码器从重建的点云中计算。双流Transformer匹配器通过交替的自注意力和交叉注意力细化描述符，生成软对应关系，并将其传递给Perspective-n-Point求解器进行姿态恢复。我们在SPE3R数据集上评估了该方法，并将FoundationPose视为当前最先进能力的代表性基准。结果表明，仅使用单张图像和重建几何，该方法实现了0.157度的平均指向误差，展现了对未见航天器的强泛化能力。

## Abstract
6-DoF pose estimation is a critical task in autonomous rendezvous and proximity operations. In the case of an unknown target, this task becomes challenging as it shall be paired with the reconstruction of the target shape model. In this article, we propose a novel framework for single-shot shape and pose estimation of unknown spacecraft objects. Given a single image, we first reconstruct a 3D shape model of the target, then estimate the relative six-degrees-of-freedom pose by learning dense 2D-3D correspondences. The image features are extracted using a frozen DINOv3 vision transformer, while the geometric features are computed from the reconstructed point cloud using a trainable dynamic graph convolutional neural network encoder. A dual-stream transformer matcher refines descriptors through alternating self- and cross-attention, producing soft correspondences that are passed to a Perspective-$n$-Point solver for pose recovery. We evaluate the method on the SPE3R dataset and consider FoundationPose as a representative baseline for current state-of-the-art capabilities. Results show reliable pose estimates achieving 0.157 degrees mean pointing error using only a single image and reconstructed geometry, demonstrating strong generalization to unseen spacecraft.

## 1. 核心问题与研究动机

- **核心问题**：在空间在轨服务、交会对接与碎片清除等任务中，需要对非合作未知航天器进行六自由度（6-DoF）相对位姿估计。传统方法依赖预先已知的CAD模型或深度传感器，而实际场景中常仅有单目RGB图像，缺乏可靠深度与尺度信息，且无法获取目标先验几何模型。
- **研究动机**：突破“需要目标CAD模型”或“需要深度/多视图观测”的限制，仅凭单张RGB图像同时完成目标三维重建与相对姿态估计，使自主导航系统能够应对未准备的、未知的空间目标，并降低传感器尺寸、重量与功耗（SWaP）。

## 2. 方法论：DreamSat-Pose框架

### 核心思想
将姿态估计问题转化为**2D-3D特征对应问题**：利用单视图生成式重建获得目标三维几何代理，再通过学习图像特征与重建点云特征之间的密集对应关系，经经典PnP求解器恢复6-DoF位姿。

### 关键技术细节（流程图：输入 → 重建 → 特征提取 → 匹配 → 姿态求解）

1. **输入图像预处理**：对SPE3R原始256×256图像，采用包围框裁剪与上采样策略（基于分割掩码获取航天器最小包围框，缩放回256×256），提升目标像素密度，改善小目标场景下的特征提取质量。
2. **单视图三维重建**：采用**Hunyuan-3D-2.0**（由DreamSat系列工作基准测试选出的最佳模型）从单张RGB图像重建目标表面网格，均匀采样1024个点作为候选3D关键点，并中心化与缩放归一化。
3. **2D图像特征提取**：使用**冻结的DINOv3 ViT-B/16**视觉Transformer提取密集网格描述符（16×16网格，每patch 768维），经线性层压缩至256维；同时使用轻量级显著性评分头选择关键点，经前景掩码过滤，保留目标区域特征。
4. **3D点云特征提取**：使用**可训练的动态图卷积神经网络（DGCNN）**，在重建点云上构建k-NN图（k=20），通过4层EdgeConv学习局部几何描述符，最大池化后拼接得到256维嵌入，与2D特征对齐。
5. **跨模态特征匹配网络**：采用**双流Transformer匹配器**（受SuperGlue启发），包含自注意力与交叉注意力交替模块（4层），并加入位置编码（2D坐标与3D坐标经MLP嵌入）。通过余弦相似度矩阵与Sinkhorn归一化生成软对应矩阵P（N×M）。训练采用含几何约束的联合损失函数：软对应损失L_soft、期望XYZ损失L_xyz、互相近邻损失L_mnn、重投影损失L_reproj，引导DGCNN与匹配器共适应。
6. **姿态求解**：选取高置信度匹配（≥6点），使用EPnP算法结合RANSAC（200次迭代）估计初始姿态，再通过Levenberg-Marquardt非线性优化最小化重投影误差，输出最终旋转矩阵R与平移向量t。

## 3. 实验设计

- **数据集**：**SPE3R**（Stanford Space Rendezvous Laboratory公开数据集），包含64种不同卫星模型，每个模型1,000张合成图像（256×256），附有真实姿态、分割掩码、3D点云等标签。背景含黑背景和地球背景，含强光照与阴影。
- **数据划分**：57个航天器训练（含80/20训练/验证划分）、7个未见航天器测试，共7,000张测试图像。另在重建实验中对每个测试航天器取100张子集（50黑背景+50地球背景）进行全管测试。
- **基准方法**：**FoundationPose**（NVIDIA通用6D姿态估计器，零样本泛化），需提供RGB、掩码、深度图（本文用真实CAD模型渲染获取，作为理想深度基准）和规范化3D网格。注意：FoundationPose依赖深度图，本文方法仅需单目RGB，对比目的是作为性能上界参考。
- **评估指标**：
  - 重建质量：3D体素交并比（IoU）、倒角距离（CD）、豪斯多夫距离（HD）。
  - 姿态精度：方向误差e_R（四元数角度距离）、指向误差e_p（线-视线角分离）、平均重投影误差（MRE）。
  - 处理**参考系歧义**：考虑四个有效右手系翻转（x,y,z; x,-y,-z; -x,y,-z; -x,-y,z），取最小误差进行评估。

## 4. 资源与算力

- **两组主要实验配置**：

  2. **基于重建模型的姿态估计**（Recon-Test）：全面模拟未知目标场景，分为“每航天器1次重建×1000张图”和“每航天器100次重建×100张图”两种子设置。

- **充分性评估**：实验覆盖了多种条件（GT vs. 重建、不同背景、不同目标尺寸、对称性影响），对比了开环（单次）与闭环（Pose refinement）。但缺少对更多不同数据集（如实际在轨图像）的泛化测试，且未进行详细的消融实验（如去掉裁剪策略、去除某种损失项等）。总体较充分，但可进一步扩展工业级验证。

## 6. 主要结论与发现

- DreamSat-Pose在Recon-Test上取得**平均指向误差0.157度**，说明即使不完全重建，线-视线定向精度依然很高。
- 方向误差对重建质量更敏感：GT-Test平均48.90° → Recon-Test平均58.73°（考虑参考系歧义后FoundationPose从123.49°降至53.35°）。
- 重建质量（CD/HD/IoU）与下游姿态精度无显著相关性，提示几何整体结构比局部误差更关键。
- FoundationPose在理想条件（含真实深度）下指向误差仅0.095°，方向误差中位数2.31°，验证了学习方法的潜力；但依赖深度使其在纯单目场景不可行。
- 对称航天器（如EO-1、CYGNSS）导致方向误差增大，指向仍准确。
- **核心结论**：单视图生成式几何代理可有效替代先验CAD模型，使未知目标姿态估计成为可能；方法泛化到未见航天器。

## 7. 优点

1. **极少的输入要求**：仅需单张RGB图像，无需深度传感器、CAD模型或多视图，大幅降低系统复杂度与SWaP。
2. **分治策略清晰**：将姿态估计拆分为重建与对应匹配两个子问题，分别利用成熟生成模型和可学习对应网络，便于模块化改进。
3. **几何约束融合**：软对应+多损失函数联合训练使DGCNN与匹配器共适应，同时结合经典PnP+RANSAC保证鲁棒性。
4. **参考系歧义处理**：通过评估四个有效翻转解决了主体框架方向不确定性问题，使评价更公平。
5. **良好的泛化能力**：在未见过的航天器模型上依然保持低指向误差（0.157°），证明学习到的特征具有几何本质性。
6. **推理速度快**：仅0.034秒/图（重建不计入），适合近实时场景。

## 8. 不足与局限

1. **重建速度慢**：Hunyuan-3D-2.0单张重建需35~40秒，严重限制端到端实时性；虽有加速版但未充分评估其对精度的影响。
2. **方向估计准确度不足**：方向误差仍有数十度（均值约58°），受对称结构、重建伪影及参考系歧义影响，与实际部署需求（通常要求几度以内）差距较大。
3. **数据集仅含合成图像**：SPE3R为渲染图像，缺乏真实在轨的传感器噪声、压缩伪影、极端镜面反射等，现实泛化性未验证。
4. **分辨率限制**：原始256×256图像中目标可能只占很小区域，虽采用裁剪策略但仍会丢失细节；未尝试超分辨率等技术。
5. **缺少完整的消融实验**：未量化每个模块（如冻结DINOv3 vs. 微调、有无裁剪策略、不同损失项权重）的贡献，评估尚不够细粒度。
6. **训练与超参数细节不透明**：未提供训练时长、学习率、优化器、批量大小等关键信息，可复现性受限。
7. **未处理多假设或不确定性**：对对称场景仅通过后处理翻转进行纠正，未在预测阶段输出多模态分布，实际应用中可能无法区分对称姿态。
