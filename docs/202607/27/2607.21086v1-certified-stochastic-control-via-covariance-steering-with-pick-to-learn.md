## 摘要
我们提出了CS-P2L，一种将协方差转向（CS）与拾取学习（P2L）元算法相结合的框架，用于在高保真随机模拟器上进行经认证的控制器综合。该方法在模拟器卷道上迭代评估策略，利用最坏情况违规收紧代理约束，并在给定置信水平下提供基于压缩的关于真实违规概率的概率保证。在一个重力不确定的航天器动力下降问题中，CS-P2L在600次卷道上认证了4.9%的违规界限，而独立的协方差转向将违规率低估了约两倍。

## Abstract
We present CS-P2L, a framework coupling covariance steering (CS) with the Pick-to-Learn (P2L) meta-algorithm for certified controller synthesis over high-fidelity stochastic simulators. The method iteratively evaluates policies on simulator rollouts, tightens surrogate constraints using the worst-case violations, and provides compression-based probabilistic guarantees on the true violation probability given a confidence level. On a spacecraft powered-descent problem with uncertain gravity, CS-P2L certifies a violation bound of 4.9\% with 600 rollouts, whereas standalone covariance steering underestimates the violation rate by roughly a factor of two.

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- **CS-P2L** = 协方差转向（CS）作为内层求解器 + **Pick-to-Learn（P2L）** 元算法作为外层迭代。
- P2L 通过**压缩理论**（compression theory）为任何数据驱动算法提供紧的泛化界：固定数据集，迭代选择最严重违反的轨迹（“腌制”的压缩集），用其更新代理问题配置，直到所有剩余轨迹均满足规范。最终输出策略的违反概率上界由压缩集大小唯一决定。

### 关键技术细节

1. **问题形式化**：
   - 定义高保真模拟器：连续时间SDE，漂移含时不变不确定参数 λ，控制采用零阶保持策略，初始状态和 λ 随机采样。
   - 规范 φ：包含安全多面体约束、控制范数上限、终端椭圆体到达前提。违反概率 p(π) = P(轨迹不满足 φ)。

2. **代理协方差转向（CS）子问题**：
   - 将模拟器围绕参考轨迹线性化并离散化，构建LTV系统。
   - 控制律：仿射反馈 u_k = ū_k + K_k(x_k − μ_k)。
   - 机会约束（安全、控制、终端）通过凸松弛（凸-凹过程）转化为线性矩阵不等式和二次约束。
   - 使用**序列凸规划**（SCP）迭代求解直到虚拟控制和信任区域满足容差（δvc, δtr = 1e-6）。

3. **P2L 外循环（Algorithm 2）**：
   - 输入：固定数据集 Z_N（N 个 i.i.d. 随机样本），初始配置 θ^(0)（包含各约束风险分配），配置算法 L，违反度量 ℓ。
   - 流程：
     1. 用 θ^(0) 调用 Solve-CSP 得到初始策略 π^(0)，并在所有 Z_N 上评估。
     2. 压缩集 T^(0) = ∅。
     3. 当存在未被压缩且违反规范的轨迹：
        - 选取违反度量最大的轨迹 ℓ 加入 T。
        - 用配置算法 L 更新 θ（收紧安全界、控制上限、终端协方差）。
        - 重新求解 Solve-CSP，得到新策略，并**用原数据集 Z_N 重新评估**（关键：数据固定）。
     4. 终止：所有非压缩轨迹都满足规范，返回最终策略和压缩集 T。
   - **理论保证（Theorem 1）**：对任意置信度 1−δ，真违反概率 p(π) ≤ ε̄(|T|, δ, N)，其中 ε̄ 通过求解压缩理论方程 Ψ(ε)=1 得到，仅依赖于压缩集大小 i、N、δ。

4. **配置算法设计（Section III-C）**：
   - 选择更新三个参数：安全约束右端项 b_m、控制上限 u_max、终端协方差 P_tf。
   - 更新规则：按违规次数线性衰减（如 b_m 每次减 γ_b·c_m，但不超过最小值），保证 Solve-CSP 仍可行。

5. **收紧策略（Algorithm 3）**：
   - 分为可选的标定阶段和认证阶段。标定时用独立数据调优配置算法 L，认证时固定 L，逐步增加累积数据集，直到 ε̄ ≤ 目标 ε。该过程保持统计独立性。
