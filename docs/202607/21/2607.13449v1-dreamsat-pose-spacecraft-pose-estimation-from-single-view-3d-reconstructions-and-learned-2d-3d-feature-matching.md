## 摘要
6自由度姿态估计是自主交会与近距离操作中的关键任务。当目标未知时，该任务因需与目标形状模型重建相结合而变得具有挑战性。本文提出了一种针对未知航天器目标的单次形状与姿态估计的新框架。给定单张图像，我们首先重建目标的3D形状模型，然后通过学习密集的2D-3D对应关系来估计相对六自由度姿态。图像特征使用冻结的DINOv3视觉变换器提取，而几何特征则使用可训练的动态图卷积神经网络编码器从重建的点云中计算得出。双流变换器匹配器通过交替的自注意力和交叉注意力优化描述子，生成软对应关系，并传递给透视n点求解器进行姿态恢复。我们在SPE3R数据集上评估该方法，并将FoundationPose作为当前最先进能力的代表性基线。结果表明，仅使用单张图像和重建几何，该方法即可实现0.157度的平均指向误差，展现出对未见航天器的强泛化能力。

## Abstract
6-DoF pose estimation is a critical task in autonomous rendezvous and proximity operations. In the case of an unknown target, this task becomes challenging as it shall be paired with the reconstruction of the target shape model. In this article, we propose a novel framework for single-shot shape and pose estimation of unknown spacecraft objects. Given a single image, we first reconstruct a 3D shape model of the target, then estimate the relative six-degrees-of-freedom pose by learning dense 2D-3D correspondences. The image features are extracted using a frozen DINOv3 vision transformer, while the geometric features are computed from the reconstructed point cloud using a trainable dynamic graph convolutional neural network encoder. A dual-stream transformer matcher refines descriptors through alternating self- and cross-attention, producing soft correspondences that are passed to a Perspective-$n$-Point solver for pose recovery. We evaluate the method on the SPE3R dataset and consider FoundationPose as a representative baseline for current state-of-the-art capabilities. Results show reliable pose estimates achieving 0.157 degrees mean pointing error using only a single image and reconstructed geometry, demonstrating strong generalization to unseen spacecraft.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：在自主交会、在轨对接、空间碎片清除等任务中，**6自由度（6-DoF）姿态估计**是关键技术。然而，当目标航天器**未知、非合作**（无先验CAD模型、无深度传感器、无合作标记）时，传统方法难以泛化。现有方法要么依赖多视图几何或深度信息，要么局限于已知形状模型。**单目RGB图像下同时实现形状重建与姿态估计**是一项挑战。
- **背景动机**：实际空间任务中，传感器受限（常仅配备单目相机），且大量空间目标（如废弃卫星、碎片）缺乏先验模型。因此，需设计一种**无需深度、无需CAD模型、仅凭单张RGB图像**即可完成未知航天器形状与姿态估计的框架，以降低传感器体积、重量和功耗，提升自主操作能力。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
- 将姿态估计转化为**2D图像特征与重建的3D点云之间的对应问题**。先利用生成式模型从单张RGB图像重建目标3D形状，然后通过学习的2D-3D特征匹配获得软对应，最后使用经典PnP算法恢复6-DoF姿态。

### 关键步骤与模块
1. **单视图3D重建**：采用**Hunyuan-3D-2.0**（基于扩散先验的生成模型）从输入RGB图像重建目标的三维网格/点云。
2. **2D图像特征提取**：使用**冻结的DINOv3（ViT-B/16）** 提取密集补丁描述子（16×16网格，768维），并通过线性投影降至256维。同时，轻量级得分头输出每个补丁的显著性，结合前景掩码选取候选2D关键点。
3. **3D几何特征提取**：从重建网格均匀采样1024个点，归一化后输入**可训练的动态图卷积神经网络（DGCNN）**，采用4层EdgeConv，聚合局部曲率与全局上下文，输出256维描述子。
4. **跨模态匹配网络**：采用**双流Transformer结构**（受SuperGlue启发），对2D与3D描述子分别进行自注意力与交叉注意力（4层迭代），得到增强特征。计算余弦相似度矩阵，经**Sinkhorn归一化**生成软对应矩阵$P \in \mathbb{R}^{N \times M}$。
5. **损失函数**：基于真实相机位姿投影构建软标注对应分布，使用软对应损失、期望XYZ损失、相互最近邻损失和重投影损失联合优化，使DGCNN与匹配器共同适应共享潜空间。
6. **姿态求解**：从软对应中选取Top-k高置信度匹配，通过**EPnP + RANSAC**（200次迭代）获得初值，再用Levenberg-Marquardt最小化重投影误差进行非线性优化，输出旋转$\hat{R}$和平移$\hat{t}$。

### 关键技术细节
- 针对小目标问题，使用**边界框感知裁剪与上采样**策略：利用分割掩码裁剪目标区域并缩放到256×256，提升特征提取质量。
- 姿态评估中考虑**框架歧义**：重建模型的自定义坐标系可能引入符号翻转，通过枚举4种有效右手系翻转并取最小误差消除歧义。
