## 摘要
低光视觉感知是针对非合作航天器的在轨服务任务的核心视觉基础，支持自主交会、姿态估计、部件检测和机器人捕获操作。星载图像遭受严重的低光退化，而配对的正常/低光空间样本极度稀缺严重限制了监督增强算法的泛化能力。为解决这一实际瓶颈，本文提出了SCI-Mamba，一种用于低光轨道航天器观测的无监督增强网络。所提框架结合了自校准无监督学习、线性复杂度的VMamba架构和Retinex物理先验，提供了一种适用于资源受限星载硬件的轻量级增强流水线。我们构建了Space Dark-1.0，一个专门的低光航天器数据集，整合了真实轨道影像、暗室硬件在环测量和物理约束合成数据，涵盖了多种光照、运动和姿态条件。与基于CNN、Transformer和主流Mamba的方法进行了全面比较，验证了SCI-Mamba在视觉真实性、色彩保真度和推理速度方面的优势。所提框架为近距离非合作空间操作提供了一种实用的低光增强解决方案。代码可在https://github.com/bitswh/SCI-Mamba获取。

## Abstract
Low-light visual perception acts as the core visual foundation for on-orbit servicing missions targeting non-cooperative spacecraft, supporting autonomous rendezvous, pose estimation, component detection and robotic capture operations. Spaceborne imagery suffers from severe low-light degradation, while the extreme scarcity of paired normal/low-light space samples severely limits the generalization capacity of supervised enhancement algorithms. To address this practical bottleneck, this paper proposes SCI-Mamba, an unsupervised enhancement network for low-light orbital spacecraft observations. The proposed framework unites self-calibrated unsupervised learning, linear-complexity VMamba architecture and Retinex physical priors, delivering a lightweight enhancement pipeline adaptable to resource-limited spaceborne hardware. We construct Space Dark-1.0, a dedicated low-light spacecraft dataset integrating real orbital footage, darkroom hardware-in-the-loop measurements and physically constrained synthetic data covering diverse illumination, motion and attitude conditions. Comprehensive comparisons with CNN-, Transformer- and prevailing Mamba-based approaches verify the advantages of SCI-Mamba in visual authenticity, color fidelity and inference speed. The proposed framework provides a practical low-light enhancement solution for close-proximity non-cooperative space operations.   The code is available at https://github.com/bitswh/SCI-Mamba

## 2. 方法论
- **核心思想**：融合自校准无监督学习机制（SCI++）、线性复杂度状态空间模型（VMamba）和Retinex物理先验，构建全序列主导的增强流水线，仅执行一次2D-to-1D展平（输入端）和一次1D-to-2D恢复（输出端），所有核心的照明估计与自校准操作在1D序列空间中完成，消除层间跨维变换冗余。
- **关键技术细节**：
  - **三阶段渐进式照明估计与校正**：
    - Stage1：初始照明估计，基于VSS1D模块从展平序列提取上下文，生成粗略照明序列i1，进行序列域Retinex增强。
    - Stage2：自校准照明校正，输入上一阶段增强结果x1和照明估计i1，通过两个VSS1D单元导出修正项，与i1相加得到i2，Retinex增强仍基于原始基础序列x0,1。
    - Stage3：最终照明校正与重建，生成i3后执行唯一一次1D-to-2D重塑、上采样、图像域Retinex分解，再经卷积输出最终增强图像。
  - **VSS1D模块**：针对展平的1D序列设计的残差式状态空间建模模块，内含1D选择性扫描核心SS1D，并嵌入序列交叉扫描生成器（SCSG）和恢复器（SCSR），在1D空间内模拟四方向（行正向、列正向、行反向、列反向）扫描，补充丢失的多维空间信息。
  - **多目标损失函数**（五项加权联合）：
    - 照明颜色恒定性损失(Loss1)：约束各阶段照明序列RGB通道均值平衡。
    - 平滑性损失(Loss2)：基于输入图像YCrCb空间局部差异自适应加权，平滑背景抑制噪声，保护边缘。
    - RGB相对响应约束损失(Loss3)：约束最终增强图像保持输入通道比例，防止颜色失真。
    - 保真度损失(Loss4)：限制各阶段中间输出与原始输入的结构偏差，防止过度增强。
    - **先验引导照明监测(Loss5)**：自动从输入亮度与梯度特征生成目标照明引导图，对纹理密集的航天器区域分配低目标照明值（增强强），对平滑黑暗背景分配高目标照明值（抑制噪声），实现差异化增强。
- **关键算法流程**：输入图像→补丁嵌入下采样→唯一一次2D→1D展平→三阶段1D序列处理（VSS1D+Retinex）→唯一一次1D→2D重塑→上采样→图像域Retinex→最终卷积输出。对高分辨率输入采用长边限制缩放策略，先预测低分辨率照明图再上采样与原始高分辨率图像进行Retinex分解。

## 6. 主要结论与发现
- **性能优势**：SCI-Mamba在推理速度上显著优于所有Transformer和现有Mamba方法（比ECMamba快18.16倍，比WalMaFa快4.61倍），峰值内存仅394.58 MB，适合星载设备。相比消融变体SCI-Mamba(2D)帧率提升23.05%。

- **数据集贡献**：构建的Space Dark-1.0填补了专用航天低光数据集空白，支持多域训练与测试。

## 7. 优点
- **方法设计**：全序列主导架构从根本上消除层间2D/1D维度转换开销，VSS1D模块在1D空间内等效实现四方向扫描，保持线性复杂度同时捕获空间关联。多目标损失函数中的先验引导照明监测自动差异化增强，无需人工标签。
- **数据集构建**：结合合成、半物理硬件在环、真实在轨三源数据，缓解合成-真实域差距。
- **工程适配性**：轻量（385K参数，4.74 GFLOPs）、低内存、实时推理，具备部署到资源受限星载硬件的潜力。

## 8. 不足与局限
- **实验覆盖**：缺乏有参考图像质量指标（如PSNR/SSIM），由于缺乏真实正常光照地面真值，只能依赖无参考指标，可能不完全反映绝对增强精度。未与下游任务（如位姿估计、目标检测）联合验证增强的实际收益。仅在单一GPU上测试，未在真实星载嵌入式处理器（如FPGA、ARM）上评估功耗与延迟。
